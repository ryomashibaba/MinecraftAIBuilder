# R44 v2 隔離オフライン専用インストーラー

新規リリース。旧SHA固定のR16/R24/R44インストーラーは実行・変更しません。
Node.js 22以降と、事前取得済みの正確な`base`（37件）・`overlay`（10件）が必要です。
ネット取得機能はありません。既存実験フォルダを入力にせず、配布用の固定ソースだけを使用してください。

```powershell
node install.mjs --base C:\isolated-bundle\base --overlay C:\isolated-bundle\overlay --out C:\new-parent\R44V2_OFFLINE_trial1
```

同じフォルダの`INSTALL_R44_V2_OFFLINE.ps1 -Base ... -Overlay ... -Out ...`も利用できます。
出力の親フォルダは既存、出力フォルダ自体は新規で、名前は`R44V2_OFFLINE_`で始まる必要があります。
成功時は46件の厳密なパス・Git blob SHA一致をJSONで出力します。
37+10件中の既知の置換は1件だけです。期待数47への緩和はありません。

短縮パス・通常パスとも、基準と各ファイルの実パスを解決してから相対化します。
不正SHA、未知・欠落・重複パス、大小文字の別名、シンボリックリンク、ジャンクション、
ハードリンク、既存出力先、入力内部への配置はHOLDになります。
全入力を検証してから出力作成。途中失敗の新規フォルダは証拠保全のため残し、再利用しません。

配置されたソースは一切実行しません。過去の承認制モデルエンジンのソースを含みますが、
本インストーラーにその起動経路・承認再利用・モデル呼出し・Minecraft接触はありません。
既存承認、証拠、ロックの探索・読み書きを行いません。ART HOLD・NOT_PREPARED・9 BLOCKEDを維持します。

テスト準備の`scripts/r44v2-prepare-git-fixture.mjs`は、取得済みGitオブジェクトから
公開済み固定ソースを別の新規テストフォルダへ取り出す開発専用機能です。
Git取得工程とオフラインインストール工程は分離されています。

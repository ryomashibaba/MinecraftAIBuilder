# MinecraftAIBuilder B198Z-R72 — 孤立床の周囲にある既存の建築質量と空洞を正確に見る

基準日：2026-10-22 JST。Draft PR #128 Open/Draft、HEADは後続のコミットで更新。R71 Windows/Ubuntu Node24 CI PASS済み。

## 目的
R71はモデル申告の入口に依存せず孤立した支持床と暫定到達領域の最近傍点を特定した。ただし単なる最短マンハッタン距離に従って橋、階段、床を作れば、意図した巨大アトリウムや屋根を分断する危険がある。R72では修復形状を作らず、**既存の実ボクセルの断面と格子上の最小直方体だけ**を資料として提供する。

## 幾何的な調査と制約
- B143最終ボクセル原本SHA、最終geometry SHA、R70元証拠、R71数値・座標を完全に再照合する。モデルの自己申告した場所や設計達成点を信用しない。
- R71で分断している上位8成分の最近傍A/B座標を含む最小軸平行直方体内の固体・空気・2セル高の空気・支持床候補を数える。直方体内XZ列に連続して4セル以上の空気が存在する数を数え、実際の大空洞かもしれない空気を人間に意識してもらう。これは空気の全てが建築上の保護対象という判定ではなく、外部の空中も含む。
- 上位3成分は、実際の最終概念ボクセルから局所の平面（A/Bの足元y）、X-Y・Z-Y断面のSVGを作成。紺＝固体、薄緑＝支持床上の位置、白＝その他の空間、青A・赤B＝確認地点。画像生成AIによる捏造や設計図の推測なし。
- 最近傍点を含む最小直方体は工事範囲・作れる道・代替案の費用・Minecraft衝突安全性の証明ではない。意図的に離れた館、浮遊した空間、巨大吹き抜けを機械的に消さない。具体的な欠落階段、必要な橋を自動断定しない。

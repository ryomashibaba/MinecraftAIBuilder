# B123 — 全15棟102階段の幅2廊下再接続・非施工監査

B122（PR #26 / HEAD 9c37620469bab209bf6e64add48b0466d2b61dd5）を基点とする独立Draft系列。B122にて代理モデル上で無干渉だったOFFICE_V1の階段#6の上下82新規廊下セル・B114仮予約2セル撤回を一体で再審査する。

## 目的と設計

- B113元ギャラリー・修復済み廊下を不変とし、B114の未施工追加分だけを撤回可能とする。
- 2×2アンカーの連結グラフを再構築し、少なくとも隣接する保護元廊下2セルを含むアンカーからの到達を調べる。
- 各階段の上下2セル幅の着地点が、同一の到達可能領域の隣接する2セルに接続するか、階段の全上下インターフェースについて検査する。
- B122で監査された候補について、B114仮セル撤回前後・82セル通路追加後を比較。変更対象以外の階段が新規に接続を失えばHOLDとし、座標付きで報告する。
- 15棟102階段の原台帳を参照し、B122→B121→B114のSHA256と施工ゲートを再検査する。
- JSON、CSV（接続口のbefore/after）、日本語MarkdownをActions成果物として保存。
- 失敗する反例（2幅ブリッジ除去、片側幅欠損、原典セル撤回、不正な階段一覧）を独立テストする。

## 認証の境界

2Dの幅2グラフが接続できても、実際のEducationブロック状態、実体衝突、ドア、踏面、床支持、施工後の通行は立証されない。B123が調べない別の建物構造問題も残る。既存の9元出口のHOLDは一切解除しない。

絶対不変：NOT_PREPARED、9ゲートBLOCKED、BuildPlan.operations=[]、worldContacts=0、施工なし、実ワールド座標なし、既存main・PRの変更/マージなし。

## B124以降の選択

B123で「他の階段への新規2幅断線」が検出された場合、その断線箇所について廊下セルの追加・撤回を含む局所ネットワーク再設計へ移行する。新規断線が検出されなければ、実機認証に必要な階段ブロック向き・階床支持・段差・通路の3Dクリアランス検証を次の工程とし、現時点のHOLDは維持する。

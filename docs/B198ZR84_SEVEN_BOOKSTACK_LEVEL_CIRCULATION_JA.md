# MinecraftAIBuilder B198Z-R84 — 七層書架段丘と立体回遊の段階的設計研究

2026-10-22 JST。既存Draft PR #128 / `feature/b198zr1-protected-architectural-revision` のみ。R83 Windows/Ubuntu両OS CI PASSを確認済み。原本Qwen出力、Freeze、main、旧成果物は保護。

## 研究目的
R83では左右1層ずつ、計2か所で研究用踊り場の配置・短い連絡面の条件を調べた。しかし元の3D図書館形態は左3層・右4層の書架段丘を持ち、その他の層が未接続だった。R84では**全7層に、元の書架段丘三角形の内側で着地点を設定**する。ただし研究用メッシュの各層が物理的に利用可能なこと、手すり/強度/衝突/ヘッドルームが成立することは意味しない。

## 研究方法
- 凍結原本SHAおよびR62/R76〜R83の証拠を原本から毎回再計算して一致を要求。B143 HOLDはHOLDのまま。
- R79由来の本物の左右書架段丘面を、屋根高度に対する正規化された高さ比で各層へ分類。左3、右4のレベルが欠けていたら失敗とする。
- R83の既存2つの踊り場は別案のまま維持し、該当する層では計画を再利用。他の5層に新たな小さな三角形着地点を作る。この三角形は既存の同じ書架段丘三角形の内挿であり、外側に飛び出す巨大な浮遊床を生成しない。
- R80の各翼の既存昇降デッキの長手方向区間をサンプリングし、各層の書架面への位置・高さ差を比較する。距離の小さい関係は人間による設計検討の起点に過ぎず、施工経路ではない。
- 各新規層への連絡面は研究用の条件を満たす場合に限り配置。翼から中央巨大アトリウムへ侵入する、水平距離が長すぎる、傾斜が大きすぎる、既存外殻・屋根・ガラス中心線と交差する場合は追加せず、**却下理由を記録**。研究用の閾値はMinecraft/建築基準の合格値ではない。

## 検証の意味と限界
CIでは、左3・右4の層の存在、R83の2着地点の維持、新たな5着地点、アトリウム保護、形状有限性、証拠照合、原本HOLD/コンパイル状態の分離、上書き拒否、HTML/OBJ/JSONの生成を検査する。**各層の本当の歩行到達、上下階への正しい接続、内部の人体幅とクリアランス、三角形同士の完全衝突、構造強度、美術審査、Qwen生成性能向上は未証明**。

# MinecraftAIBuilder B198Z-R64 — 独立した最終ボクセル床・空間ネットワーク検査

2026-10-22 JST / Draft PR #128 継続。正式採用や施工は未承認。

## なぜ
既存R43/R61はモデルが自ら宣言した entrance・destinations・functionalZones の検証なので、チェック項目を意図的に簡単な場所へ限定すれば建築全体の中実・狭い空間・孤立を見落とせる。R63は体積や高さの変化を追えるが、実際の歩行空間の分布を示さない。

## R64実装
- `scripts/b198zr64-unclaimed-floor-connectivity.mjs` は厳格に保存原本SHAとB143最終概念ボクセルgeometry SHAを照合し、モデルのspatialPlanを一切使用せず、全ローカルグリッドから立てる候補位置を抽出する。
- 立てる候補の条件は直下に支持ボクセル、足元と頭上の2セルが空気であること。R3と同型の上下1段を含む隣接移動で抽象連結成分を列挙する。全候補がいずれかの成分に属することを検証。
- 同一足元Yの2×2空気床パッド数、候補位置の高さ別分布、連結成分数、最大成分に属する位置数、ローカルy<=2の候補を含まない成分にある位置数をレポート。
- 大きな分断や幅不足、低層から切れた上層などは『人間が見るべき兆候』として示し、自動不合格とはしない。中庭、離れ、浮遊広場など意図的な構成を禁止しない。
- 物理ブロックの当たり判定、現実の入口・扉、階段形状、避難安全性、用途に応じた動線、屋外/屋内の判別は行わない。1セル幅の抽象移動はMinecraftキャラクターの実機歩行証明ではない。
- R60 ZIPレビューでB143コンパイル合格の保存原本にのみ追加。B143 HOLD時はR51図のままでR64最終ボクセルを捏造しない。R60_INDEX.htmlへR64 HTMLのリンクを追加。

## 回帰テスト
モデルのspatialPlanが架空座標になっても同じボクセルから同じ統計値が出ること、支持された独立高床の検出、幅1のみの床、元原本とgeometry SHAの改ざん拒否、B143未コンパイル原本拒否、既存レポート上書き拒否をオフラインで確認。新規CIワークフローは増やさず既存R60 Windows/Ubuntu Node24に統合。

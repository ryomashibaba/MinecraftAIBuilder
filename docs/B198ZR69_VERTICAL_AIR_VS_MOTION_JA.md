# B198Z-R69 — 吹き抜け空気と支持床移動を分離する立体空間監査

2026-10-22 JST。MinecraftAIBuilder Draft PR #128 継続。ユーザーから新たなQwenモデル推論・施工承認は受けていない。

## 改善点
R68は同一階高での頭上2セルの空気連結を調べたが、上下方向へのつながりは把握できなかった。R69は最終B143概念ボクセルだけから、すべての3D二セル高空気領域と、実際に支持床を持って一段まで上下移動できる抽象移動領域を**別々に全探索**する。

## アルゴリズム
- 保存原本のSHA256、厳格B143最終ボクセルgeometry SHA256を実コンパイラで再確認。モデルのspatialPlan・自己申告の入口、閾値、部屋名には依存しない。
- 3D空気グラフ：足と頭の2セルが空気なら、上下・前後左右の6近傍がつながる。支持床の有無はこのグラフに影響させない。アトリウム、吹き抜け、階段のない垂直シャフトも空気として接続される。
- 3D支持床移動グラフ：下に固体支持があり、足＋頭の2セルが空気である候補位置のみ使う。同じ高さの4近傍に加え、前後左右への移動で1段だけ足位置を上下できるという既存R3/R64の**抽象ルール**を利用する。上昇時の現位置の追加クリアランス、下降時の移動先のクリアランスも調べる。
- 空気でつながった同一領域に、互いに支持床移動が切れた候補が2つ以上あれば、独立人間審査の優先項目にする。意図的に別棟にしたり巨大な空洞にしたこと自体は不合格にしない。
- 数値：全二セル高空気候補、支持床候補、3D空気成分数、支持床移動成分数、上下を移動できる抽象的な辺数、空気はつながるのに支持床移動は切れた領域数。グリッド全位置の集計数を照合し、最大12成分の内訳を報告。

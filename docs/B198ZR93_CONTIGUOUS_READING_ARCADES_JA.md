基準：2026-10-23 JST。MinecraftAIBuilder c01 のART-FIRST研究。既存Draft PR #128、ブランチ `feature/b198zr1-protected-architectural-revision`。元R92の全館ソースと過去証拠は変更せず、新しい比較3Dモデルを追加する。

## 直前R92のCI問題
GitHub Actions `39886184526` / `39886190083` はWindows・Ubuntuともキャンセル。ログに「The operation was canceled」「Promise resolution is still pending ...」が出ており、元R60〜92を**35以上のテストファイルで一度に並列実行**し、`timeout-minutes:12` に到達したことが主因。R92の完成・合格と解釈するのは誤り。

新しいワークフローを増やさず、既存R60 YAMLのみ次に変更：
- Push/PRは4つの中核試験：R60一括出力・R84正規化証拠・R85厳格証拠再検証・R93全館建築追加。 `--test-concurrency=2` によりCPU競合を抑える。
- **完全なR58〜R93履歴の検証を削除しない**。同じワークフローの `workflow_dispatch` （手動実行）で全テストを従来どおり試験可能に維持する。`timeout-minutes:30` は手動の全件長時間試験も扱うため。
- CIが緑の場合の意味は**通常のPush/PRではこの4スイート合格**であり、過去全テストを毎回実行した意味ではない。フル検証は別途要求し、明記する。安全ゲートの評価を緩めない。

## R93：元の床に結び付く建築的な室内の再設計
R79の元3D閲覧床の隣り合う三角形を、R84が選んだ7つの室位置から実際の共有辺でBFS探索した結果、各室で9面のつながった床領域（合計63面、正規化平面ではなく斜面面積の合計約0.638）がある。これは空間研究の源であり、荷重・人体の平面可用域の証明ではない。

各室の源面から実際のX/Z断面を取って、5つの連続する支点を設置。4区間ずつ、**合計28の長い建築ベイ**を作る。外殻側に縦へ伸びる書架壁、上に片側へ傾く帆/灯籠の採光ルーフ、読書用ベンチを連続した実3D三角形として作り、左3層はSAIL、右4層はLANTERNに意匠を分ける。各断面の床始点は**本当に存在する源三角形**から得る。中央吹抜け `|x|<0.4` を侵食しない。元の屋根までの局所高さ条件とR87家具への有限線分交差を試験し、合格しない区間は出力しない。

直接コード実行結果：
- 元のR92 **4,306**面を完全保持、新規**168**面、全館**4,474**面。
- 元の連続した63テラス三角形から源面積0.6383713の研究域を抽出。
- 左右7層に4区画ずつ、計28区画を生成。研究用候補の家具干渉拒否0。
- 合理的な3Dプログラム空間が見えてくる一方、環境のインテリア美術審査、自然言語→3D汎用生成性能、実用的床支持・頭上高さ、階段・手すり・実人体幅、Minecraftの歩行は**まだ未認証**。

# MinecraftAIBuilder B198Z-R79 — 新規の原創パラメトリック立体建築研究

基準日：2026年10月22日 JST。`ryomashibaba/MinecraftAIBuilder` / `feature/b198zr1-protected-architectural-revision` / Draft PR #128に継続。R78 Windows/Ubuntu 両方CI PASS確認済み。

## 今工程の成果物の性質
R77/R78で定義した図書館の中心着想、左右の曲面翼、中央の全高の負の空間、書架閲覧の段丘、ガラスラウンジの関係を**OBJの3D三角形表面モデル**で新規構成する。R78の紙上のグラフを超えて、実際に立体座標を持つ形態研究案と、同一三角形から投影した4視点（正面・斜視・側面・俯瞰）、正面断面と中層平面を出力する。

ただし、正規化単位の美術研究モデルであって**過去のQwen出力やB143モデルの再コンパイルではない**。寸法を勝手にメートルやMinecraftブロックと解釈しない。メッシュの水密性・支持構造・本当に階段を上れること・ゲームでの衝突・設計美術の人間合格は一切未確認。研究での実空間と現実で歩ける空間を混同しない。

## 造形
- 中央アトリウムは左右翼の内縁を明確に離して全高の空間を作る。高所で橋を横切らせて空間を塞がない。
- 左右の曲面翼は異なる最大高さとねじれ、前後で変わる屋根稜線、外縁と内縁に明確な厚みを持つ。遠景で2つの矩形箱として読ませない。
- 左右翼の内側には書架・閲覧段丘を想定した複数のテラス面を置くが、上下連絡と衝突可能性は認証しない。
- 右側上層のガラス観察ラウンジを独自の楕円外皮として配置。主要構造との実際の接合や利用者の到達経路は次に設計する課題。
- 建築の長さ・高さ・曲率を変える設計自由度を残し、リング、塔、アーチなどの他の要素を形式的に禁止しない。今回の形は固定採択ではなく検討案。

## 実装
`scripts/b198zr79-parametric-library-massing.mjs`：保護済み原本SHA、R62→R76→R77→R78の出典を原本から再計算し、保存R78との完全一致を確認。純粋な関数`buildR79OriginalMesh()`で左右の体積外皮・書架段丘・ラウンジの三角形面を構築。メッシュ座標から静的SVGの正面/斜視/側面/俯瞰、断面・平面を描画。OBJは他の3Dツールから開くことができる編集可能な研究モデルの表面形式。

既存R60の一回オフラインZIPレビューに追加する出力：`R79_ART_STUDY_EVIDENCE.json`、`R79_TIDAL_LIGHT_ART_STUDY.obj`、`R79_ARCHITECTURE_FOUR_VIEWS_AND_SECTIONS.html`。過去のR48/R54がB143 HOLDでも、R79を旧出力の成功として扱わず、新規モデルの基礎研究として明確に分離する。静的SVGは外部ネットワーク・実行スクリプトなし。R60_INDEX.htmlからリンク。

## 検査
R79の単体テストで、左右の高さ非対称、中心空洞と面の交差禁止、書架段丘とガラスラウンジの存在、原本出典改ざん拒否、B143 HOLD保護、OBJの実三角形と六面の静的図、出力上書き拒否を確認する。R60結合と既存全工程のNode24テストは既存Windows/Ubuntu Actionsで継続実行。CI成功は出力・数理的制約の検証結果であり、建築美術PASSではない。

# B198Z-R43 — 立体造形・実空間・動線を同じ最終ボクセルで照合する

## 目的

R25の本物のQwen原本はCUT材質違反でB143 HOLD。仮想修正後も中実外殻、塞がれた機能領域、不成立の入口、経路分断がある。一方R41/R42では、後日の単発生成へ向けた短い指示と、元の3D形状を保持するJSON冗長性削減の基盤を整えた。

R43では、**モデルが宣言した用途・内部・外部の構成が、最終ADD/CUT結果のどこに存在するかを人間が断面ごとに確認する**。形式合格を独創性・美観合格と混同しない。

## 実装

- `source/ai/b198zr43-sectional-architecture-review.mjs`
  - `inspectR43ArchitecturalSections(raw)` は保存した四キー原本文字列をそのまま解析する。
  - R4/B143/R3既存検証器を呼び、最終コンパイル済みボクセルを取得。入口や書式に違反があればHOLD。元データを補修・再生成しない。
  - 外殻の高さ別スライスの占有数・XZ寸法範囲、ソース形状語彙・立体の層変化を測る。**これらは造形美・独創性の点数ではない**。
  - 入口（1）、目的地（最大3）、機能領域（最大3）、保護すべき空洞（最大2）の位置で、上から見た小さなXZ断面を表示可能な行データとして返す。断面は最大17×17セル、座標はB143のローカル概念グリッド。
  - `#` は最終ソリッド、`o` は足元に支持床があり頭上空間が空いている立ち位置、`.` はそれ以外の空気。注目点は`E`（入口）、`D`（目的地）、`Z`（機能領域）、`V`（空洞）。注目点の印があっても実際に立てることを意味しない。別途 `anchorStandable` を確認する。
  - R3の正式な経路・空洞・機能領域結果を添付し、埋め戻し、接続不足、使えない機能領域の**測定根拠のある設計上の改善ヒント**を返す。
  - モデル宣言の契約閾値は第三者独立契約ではなく、モデルが自己申告したもの。閾値を意図的に緩くできるので、R3の合格も完成・独創性・美観を認証しない。

# B107 — 建物全体の外観・屋根・内装・階段図を視覚的に改善

## 目的と実装範囲

B105/B106の、実データに一致するオフライン立体ビューを守りながら、壁/屋根/窓/家具の非常に単純な立方体表示から建物用途ごとの建築的な造形へ進める。建物全体の印象と内部を評価しやすくする。B100〜B106および凍結原本は変更しない。

- `source/parallel/b107/main/b107-visual-architecture.mjs`：B105のセルを全て根拠とする装飾専用立体ボックスを生成。5用途別の立体屋根（住宅の稜線状、ホテルのパラペット、集合住宅のテラス、オフィスの積層屋根、図書館の鋸歯状トップライト候補）、窓枠・窓ガラス、外壁リズム、集合住宅のバルコニー帯、室用途別の家具形状・細部、階段コア内の概念踏み板・手すりを追加。元の物理セルにない外部床面は生成しない。
- `source/parallel/b107/main/compile-b107.mjs`：5用途×3案で旧B105屋根/窓/家具・B106階段概念リンクと対応する新しいレビュー造形を再現生成し、差分と監査結果をレポートへ出力。B106の元のビューアーから**別のB107 HTML**を生成し、追加レイヤーの表示切替を組み込む。
- `source/parallel/b107/main/compile-b107.test.mjs`：新規30件、総472件。屋根・窓・家具・階段の元セル根拠、入力無変更、SHA256改変検出、未承認施工防止、HTML自立性など。
- `scripts/verify-b107-safety.mjs`：元のB105/B106ソース形状に対する対応、構造データの不変性、9ゲートBLOCKED、BuildPlanゼロ、worldContactsゼロを検証。
- `.github/workflows/qa.yml`：CIによる生成・テスト・ArtifactsへのレビューHTMLとJSON保存。

## 正しく解釈すべきこと

**B107は実Minecraftの建物を施工・完成する機能ではなく、読み取り専用の立体造形レビュー改善。**
形状には小数セルの視覚表現が含まれ、Minecraft Educationの物理ブロックの寸法・向き・互換性を保証しない。特に屋根の雨仕舞/荷重支持、ドア・窓の実動作、家具の実形状、階段の実移動や避難、見た目の人手による高品質評価は未認証。

B106の元の仮想データと一致することは監査できるが、**美観や完成度は人間がプレビューを見て評価する必要がある**。自動テストのPASSと「完成度が高い」は同義ではない。Minecraft Education 26.3を対象候補としているが、検証済みBlockStateは0件のまま。

## 安全
`readiness=NOT_PREPARED`、9ゲート`BLOCKED`、`BuildPlan.operations=[]`、`commandCount=0`、`worldCoordinates=null`、`worldContacts=0`、`constructionApproved=false`。
凍結原本、旧296未承認室、18保留室には触れない。Minecraft接続・施工・自動配置は一切行わない。

B108ではHTMLプレビューの実ブラウザでの視認性・描画性能を測り、各建物の主要な造形欠点を修正する。続いて実Education版のバージョン固定・読み取り専用BlockState実資料を検証し、実ブロック化は別工程・別承認とする。

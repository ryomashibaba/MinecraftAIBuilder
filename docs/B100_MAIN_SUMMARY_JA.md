# B100 成果報告 — 特定建物依存から汎用設計へ

## 方向転換
Minecraft Educationを先に完成し、Javaは将来別アダプター化。B99は回帰試験・設計課題の参照資料とするだけで、B99の中庭回廊/R013を汎用エンジンの暗黙の標準形にはしない。旧296候補・18保留の施工許可も出さない。

## 新規実装
`source/parallel/b100/main/` に以下を追加。
- `b100-universal-design.mjs`: ルールベース日本語解析、共通Building Brief、可変階数・不規則床マスク生成、垂直コア候補、BFSを用いた連結した幅2の仮想通路、フロア占有を競合させない居室配置、入口候補と代理指標、多様性の床面形状差率、設計拒否と安全バリデータ。
- `compile-b100.mjs`: B99参照ファイルのハッシュ固定と安全チェック、5用途×3構成の設計生成、Education優先ポリシー固定、実施工コマンドゼロのB100レポート生成。
- `compile-b100.test.mjs`: 40件の自動テスト（陰性テスト含む）。
- `render-b100.py` → `B100_UNIVERSAL_DESIGN_REVIEW.html`: ローカル自己完結の5用途/3案/全階の平面図比較（イラストではなく座標から計算した結果を表示）。
- `B100_GENERIC_DESIGN_REPORT.json`: 生成器の全結果。再現可能なJSON。

## 実測結果
- 5用途: 一戸建て、ホテル、集合住宅、オフィス、図書館。
- 各3案・計15案。2/5/6/6/3階の構成を合計66仮想フロア分生成。
- 381概念室。各室は名目2セル入口候補に接する（ただし**実ドアではない**）。
- 床セル形状差（各用途の3案の最小値）：住宅24.825%、ホテル7.333%、集合住宅8.235%、オフィス7.552%、図書館15.807%。これは輪郭が異なるという定量的指標で、デザインの美しさや無限のバリエーションを保証しない。
- 全建物に共通して使えるIR／検査器と、異なるコア位置・床レベル・部屋プログラムを確認。
- B100専用40件、B92-B99回帰211件、合計251/251 PASS。
- B99の1,599ファイルはSHA-256一致。施工許可0、実コマンド0、世界接続0。

## 今回の限界
B100は「完成建物生成」ではなく **再利用可能な設計基盤の最初の実装**。実3Dの床・柱・壁・外観・階段・ドア・家具、出口までの移動可能性、法的基準、Bedrock実ブロック適合、施工計画は未成立。用途と階数の解析はルールベース試作で、自由な日本語の正しい意味抽出も保証しない。プレビューは2D計画図で、Minecraftの実3Dスクリーンショットではない。

## 開発優先度の変更
局所1室の探索→全建物の再利用性・建築多様性・実用品質・Education安全施工を主評価へ。特定用途の成功だけで進まない。今後、用途別必須機能、遮光、コア/ドア/屋根/窓の3D実現性を追加する。

# MinecraftAIBuilder — B198Z-R87 七層の閲覧建築を3Dに戻す
基準日2026年10月22日（JST）。対象は c01「海沿いの曲面的未来型公共図書館」、既存Draft PR #128、ブランチ `feature/b198zr1-protected-architectural-revision`。

## なぜこの変更か
R83〜R86で着地点、候補ルート、中心線・幅を検討してきたが、利用する図書館という建築像はまだ不充分だった。R87は幾何テストの追加自体ではなく、現実に研究用三角形メッシュを追加して**7つの閲覧空間と上層ラウンジの内装**を3Dで比較できる状態へ進める。

## 新しい形態
- 左（西）3層は「帆状の読書コーブ」。出典R79の左右非対称外殻と連続する斜上方向の二枚フィンを持ち、湾曲海岸沿いに居場所のリズムを作る。
- 右（東）4層は「灯籠型の書架ギャラリー」。外殻向きの薄い書架壁と異なる高さの3枚フィン、低い閲覧カウンターを配置。左右を単純コピーしない。
- 各層では源の本当のR79閲覧テラス面から7面以内を取り出して床意匠を作る。棚・机は元の一枚の三角形内に接続して作る。天井の研究高さ、外殻三角形の交差を調べ、衝突する壁・意匠装置を無断追加しない。
- 透明な上層観測ラウンジ内部へ薄い視認リングと4つの観測席を追加する。入口からの到達を証明するものではない。
- 正面・斜視・側面・俯瞰SVGと3D OBJで**実際の立体変化**を審査可能。独立したレビューなしに採択しない。

## 原本と審査の連続性
R86以前の面は切断せず、前段の証拠JSONを原本SHAを含め全段再演算・一致要求。7つの閲覧領域は3対4の元R84帯域を守る。許可のないモデル推論やMinecraft世界操作は行わない。R79源のガラス極点に元々あるゼロ面積三角形は歴史を変えずに温存し、**新規追加した面のみ**ゼロ面積がないか検査する。既存研究モデルの微小面と本当の建築完成を混同しない。

7層が設計上示されたことは、駅の通路のような機能する建物を意味しない。最低有効幅、階段・踊り場の確定した連続、床荷重、実測クリアランス、居室容積、書架の独立美術審査、人間がMinecraft内で歩行したこと、モデルが自力でこの形を生成したことは**認証していない**。R87の種別は現在のc01個別美術研究であり、自然言語→設計の汎用正解テンプレートにはしない。

# B122 — B121で見つかった長距離2幅通路の全長独立監査（非施工）

B121は直線/180度折返し階段・B114の未施工廊下を同時に検討した。保護元廊下とB113修復廊下を保持する最終検証では、15棟66階102階段のうち8保留出口・7階段・2,100試行で、OFFICE_V1 #6 上階L2に条件付き1案が見つかった。ただし仮廊下2セルの見直しと、上下の計82セルという長い新規廊下が必要で、全長の3D確認は未完了だった。

B122では次の条件を「可否を決めるための監査」として設ける。成功候補を自動採用するためのテストではない。

- B121の固定SHA256・B114/B113資料を出所照合する。
- 上下の2本の新しい通路全セルを別実装の幅2・連結判定で再計算。入口・終端・未到達セル・追加セル差分を再検査。
- 元の床/部屋/コア、他階段占有、B117の仮床開口、B105静的ボクセルの頭上2ブロック、他階段の踏面・支持ボックスとの交差を全長で測る。
- B114の未施工仮廊下予約を2セル撤回する前後で、幅2アンカーによって元の廊下へ根を持つ予約セルの数が増減するか独立比較する。元の廊下またはB113修復済み廊下の削除を絶対禁止。
- この段階で旧B114案を撤回した場合の **他のすべての階段との接続は認証しない**。あくまで元廊下ネットワークへの2幅到達可能性と、再配置で切断が増えたかの検査。
- 7つの合成反例テスト＋5つの全15棟安全テスト、JSON/CSV/Markdownで再現可能な記録を保存。

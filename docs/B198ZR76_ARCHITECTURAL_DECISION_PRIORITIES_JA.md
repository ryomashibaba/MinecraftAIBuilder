# MinecraftAIBuilder — R76 建築改善の次の判断を整理する

基準日：2026-10-22 JST。既存Draft PR #128のみ。既存Freezeとmainを変更せず、R75 Windows/Ubuntu Node24 CIが両方PASSしたことを確認して開始。

## この工程の実効目的
R58〜R75は強力な検査・証拠の仕組みを積み上げたが、モデルが実際に美しい公共図書館を作れるようになったことを示していない。検査をむやみに追加し続けず、元のユーザー要求への改善方向を短い審査レポートにする。R76の『優先順』は**意思決定の依存関係**に基づくもので、数値的な品質スコアや美術評価ではない。

## パッケージ順
1. **原本の成立**：R49/R58およびB143。B143 HOLDなら、最終概念ボクセルは存在しないという前提を維持し、他の幾何的結論を出さない。元の形状・造形意図を尊重しつつ、**将来あらためて許可された場合にのみ**完全なB143原本を作り直す。
2. **本当の利用性**：B143がコンパイルできた場合のみ、R61/R64/R65/R69/R70/R71の支持床・入口候補・踊り場・上層施設の連結を人間が確認する。モデル申告の部屋や最短ペアは、入口や歩行経路を証明しない。
3. **圧倒的造形・大空洞の保存**：R66/R67/R68/R72/R73の屋根・空気・外形の根拠を確認し、吹き抜けを埋めず外観・立体的な公共空間を守る。実Minecraftの衝突・人間の美的審査とは別。
4. **自己申告と実形状の整合**：R43/R61等のモデル宣言・幾何の不一致を調べる。モデルが自身に都合のよい閾値を置いていても達成や品質の認証とみなさない。

## 何が出力されるか
`scripts/b198zr76-architecture-next-decisions.mjs`：元のraw SHAとB143 geometry SHA、R61〜R74を含むR62保存レポートを**原本から全面再計算**して一致させる。改ざん、古い資料、R62の偽の品質PASSは拒否。R60の既存1回ZIPレビューから、新たに`R76_ARCHITECTURE_PRIORITY_REVIEW.json`と`R76_ARCHITECTURE_NEXT_DECISIONS.html`を出力し、R60_INDEX.htmlから開く。コンパイルできない原本でも『まず原本成立』を表示するが、存在しないボクセルの警告を創作しない。

元の4つの独立人間品質基準（未来的な海辺の図書館、全高アトリウム、左右の本棚、ガラス張りの星空ラウンジと曲面外装の統合）はすべてNOT_REVIEWED。機能と美術は実際の人間による目視・用途レビューが必要で、ソースやテストだけでは満たしたと判定しない。

## 境界
レビュー順は機械が決めた施工順序ではない。形状の自動変更、設計案採択、モデル再生成、世界操作、施工を行わない。実Qwenの再推論には別途の新しい一度きりの明示的な許可が必要。

`readiness=NOT_PREPARED`、`constructionApproved=false`、`executionAllowed=false`、施工ゲート9個すべてBLOCKED、`BuildPlan.operations=[]`、`modelCalls=0`、worldContacts/Reads/Writes=0を維持。

# R164：同条件で3案の上部外壁・屋根全周と実外観4方向を評価（2026-10-25）

## R163の確認済み限界
R162：屋根付きの高い実室。R163：外壁の高窓が本当に屋外と実室に接することを確認。しかし、元の検証はガラス窓と屋根内側のサンプルであり、**上部の壁全周の小さな穴や屋根の端の欠落**まで網羅していなかった。前工程の「美術的な完成」は未承認。

## 今回の実装（検査の対象を限定して誇張しない）
- `source/ai/r164-envelope-continuity.mjs`: R163で得た実B143ボクセルを別処理で再走査。各室の上部壁全周の**全座標**について外壁・実ガラスが存在するか、ガラスが証明済みの窓だけか、室の実屋根が壁端まで覆うかを検査。
- 加えて、屋根下の各高室の実空気セルから3Dの上下左右の空気経路を探索し、**上部空間が屋外の自由空気へ直接つながる穴**がないか調べる。ソースの新規CUTで屋根・壁に穴を開けた負のテストは必ず失敗させる。
- `scripts/r164-exterior-audit.mjs`: B143実ボクセルから正面／背面／西／東の4方向と上方の計5方向を**投影アルゴリズムで厳密描画**。中央・西側・東側、同じ敷地と3室・設備の合計15枚のSVG、元B143 3Dビューア3つ、ソース・実ボクセル・監査JSONの合計26ファイルを既存品質CIのArtifactで保管。イメージ生成・空想レンダリングではない。
- `scripts/r164-exterior-audit.test.mjs`: 独立B143シーン3案、原本保持、安全HOLD、完全外殻面検査、屋根CUTと壁CUTの負試験、生成物の改変禁止をCIで実施。

## 必ず区別すること
今回のR164は**上階（y6以上）の室の外壁・屋根**の限定監査であり、下階の外部入口・雨密性・実際のMinecraft光源と天候・現実世界の耐久性・全体の建築美術を合格とはしない。「実4方向の視覚証拠ができた」と「美しい建築になった」は別の主張。Qwen/Gemma新規呼び出し0、原モデル回答の変更0、ワールド接触0、ART HOLD／NOT_PREPARED／9×BLOCKED／空BuildPlan／PR #128 Draftのまま。次工程では、実外観と室内導線の目視を設計選択に反映させる。

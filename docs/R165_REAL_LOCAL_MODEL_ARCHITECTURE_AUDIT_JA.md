# R165 — 実Qwen/Gemma未知用途3件の、原文から外観まで一貫した証拠審査

## 検証の焦点
R156/R157の3用途（住宅・店舗・研究施設）の実モデル出力を取得しても、それをR164で開発した4方向＋屋根の実ボクセル比較で判定する経路が無かった。R165は**新しい建築テンプレートや微装飾を追加せず**、すでに保存された実B143ソースを同条件で比較する。

`scripts/r165-local-model-architecture-audit.mjs` はR156出力ディレクトリを**読み取り専用**で検査する。用途ごとにMODEL_RAW_ORIGINAL.txtのSHAとR156マニフェストの一致、R134モデルレポート・真のB143ソース＋コンパイル実ボクセル、部屋への2幅ソース経路と設備の到達を独立照合する。色・材質・名前を完全除外した正面／背面／西／東／上面の投影占有パターンのSHAを算出し、ペアの形状収束を検出する。実ソース検証に成功したときだけ各方向の実ボクセルSVGを保存する。問題のあるケースはHOLDとして理由を出す。絶対に美術PASSや施工許可を作らない。

## 使い方
今までと**同じ** `RUN_R157_UNKNOWN_USE.cmd` をWindowsのローカルOllamaが動く既存リポジトリで実行する。内部は`git pull --ff-only`の後にR156（最大3回の新しいローカルモデル呼び出し、再試行無し）→R157（意味空間比較）→**R165（真正ボクセル5視点の比較）**→全原文と監査物のZIPを一度で実行する。原文・既存ビューア・マニフェストの上書きは一切しない。途中で推論失敗の場合も、一部証拠があるかぎり保管し、認証できたふりはしない。ZIP内`R165_COMPARE.html`を開けば3用途の実B143と全方位画像が一覧できる。

手動で既存R156結果の独立レビューだけを行うなら `node scripts/r165-local-model-architecture-audit.mjs --study <出力フォルダ>` を実行する（R165結果の再実行・上書きは禁止）。

## 誠実な判定の境界
- GitHub Actionsの`fetcher`による模擬テストは本物のQwen/Gemmaではない。ローカルのモデル名やHTTPの自己申告からLLM提供元の完全な外部認証をすることもできない。**CIが189+のテストでPASSしても、新規モデル実推論の成功や美術品質を主張しない**。
- B143バイト再コンパイルとsource SHA、geometry SHA、元応答SHAに不一致があれば個別にHOLD。元モデルが4室を望み共通エンジンが3室のみサポートする場合も誤魔化さずHOLD。形状が異なるだけで良い建物とは認めない。
- ART HOLD／実Minecraft歩行未実施／ワールド接触0／施工NOT_PREPARED・9 BLOCKED・空BuildPlan。旧Qwenの原本、既存のR156/R157およびDraft PR #128を保護する。

次の実質的な判断は実3用途の`R165_COMPARE.html`の見た目から行い、形態の収束・用途適合不良が確認された箇所だけ共通エンジンを改善する。

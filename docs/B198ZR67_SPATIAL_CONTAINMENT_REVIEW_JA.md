# B198Z-R67 — 屋根と水平周囲構造の実ボクセル調査

2026-10-22 JST。MinecraftAIBuilder Draft PR #128。R66後続、実Qwen新規推論とMinecraft操作なし。

## 目的
R66はモデル宣言によらず屋根の真下にある立ち位置を数えられるが、屋根しかない開放デッキを図書館や室内と同一視する危険が残る。R67は頭上の固体と周囲の固体との距離を同時に計測し、場所の用途を過剰に推測することなく人間の審査を支援する。

## アルゴリズム
- 保存した元モデル回答の原本SHAとB143最終概念ボクセルSHAを再検証し、最終ADD/CUT後の占有セルのみ使用する。モデルのspatialPlanや自己申告の部屋座標・達成閾値は一切使用しない。
- 直下が固体、足元と頭上1セルが空気の候補セルを全探索。真上にさらに固体があるものを屋根代理として扱う。
- 前後左右の4方向について、足元または頭上1セルの高さに固体が存在するまでの最短距離を線形走査で求め、8セル以内（近接）および24セル以内（拡張）の3方向/4方向の候補数を分離する。レイ照射の大量繰り返しは避ける。
- 屋根代理＋24セル以内の周囲3方向の固体がそろった候補、同条件の2×2床候補、足元Yごとの件数をJSONとHTMLに表示する。
- 柱・家具・外壁・仕切り・橋の下も同様に検出される。**3方向を満たすことは室内・実際の家具配置や使用可能性の証明ではない**。逆に24セルより遠い壁を持つ大ホールや意図的な開放庭園を失敗扱いしない。

## 既存経路への接続
- R60 ZIPレビューのB143合格時のみ、R7/R61/R64/R66と同じ検証済み原本からR67を生成。元のR54/B143がHOLDならR51の外接形状のみでR67の最終ボクセルを捏造しない。
- R62次回設計指示にはR67からの注意点を追加。入力レポートは原本からR67を再算出して数値と懸念を照合し、R64およびR66との支持床数・頭上固体数の整合も確認する。
- 1回限りのモデル推論承認は消費済み。次回の実推論は別の明示承認が必要。自動設計改訂、自動合格、施工ゲート解除は禁止。

## CIと安全
合成幾何の屋根だけの床・四周の壁を持つ床・柱だけの擬似室内・開いた中庭・巨大な中実塊・SHA改ざん・上書き拒否などを検証。既存R60 Windows/Ubuntu Node24 CIに統合し、新しいGitHub Actionsワークフローは追加しない。

`NOT_PREPARED`、constructionApproved=false、executionAllowed=false、9ゲート`BLOCKED`、BuildPlan.operations=[]、推論0、Minecraftの接続/読取/施工0、Freeze/main/既存原本不変更。テスト成功は実際の建築生成品質改善の証明ではない。

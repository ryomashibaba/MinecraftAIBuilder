# B118 — 幅2廊下の残り9入口・安全な非施工代案探索

B117で確認した15棟66階、102階段、816仮想床開口、204上階踊り場支持候補および9件の通路HOLDを固定ダイジェストで引き継ぐ。B117の元フロア・部屋・階段・支持案を変更せず、原位置の階段出口から広さ2マスを確保する案を探索する。

## 方式
- 幅2の踊り場から「両レーンを同時に通れる」向きだけを2方向走査。最初の2列×2マス、各部屋・コア・階段占有・床不足・他の**仮想**床開口を保護する。
- 2×2セル集合が4近傍で連続し、B113元通路＋B114順次追加候補の隣接2セルへ達する案をB114とは独立に探索する。最長や最大試行などの恣意的な成功指標は設けず、可能/不可能を明示。
- 原位置の経路候補はB116 3D代理ボクセル・移設済み仮想階段踏み面を使って再検証し、干渉時は候補を除外する。床開口は実際に作られていないので、あくまで**両方の仮想設計が競合しない**条件に過ぎない。
- 原位置で失敗したものは、踊り場を1〜2セル平行移動した場合の**概念上の候補**のみを参考資料へ記録。階段の踏み面・支持・人体包絡を移し替えていないので、代替階段の成立や到達性を認定しない。現行の9件は人間承認までHOLDを維持する。
- JSON、CSV、日本語レビュー、合成ユニットテストと15棟全件の統合テストをCIで検証する。

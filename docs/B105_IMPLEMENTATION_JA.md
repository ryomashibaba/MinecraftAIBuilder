# B105 — 建物全体の屋根・外装・窓・内部と階段接点の概念3Dモデル

## 目的
B104で生成した間取り・回廊に対し、建物全体の外装と内部を追加する。汎用5用途に共通する読み取り専用の設計IR。Minecraft Educationを優先しJava版は将来拡張。

## 新規実装
- source/parallel/b105/main/b105-building-volume.mjs
  - generateB105: B104の部屋・コア配置から、屋根・外装・窓・地上出入口候補・部屋家具候補・階段接点をグローバルな仮想XYZに生成する。実ブロック命令には変換しない。
  - 段状屋根: 当該階に床が存在し上階に床がないセルに概念的屋根キャップを配置する。中庭・吹き抜けの空洞をそのまま維持する。雨仕舞・耐荷重は未認証。
  - 外装: 当該階のフットプリント外周に隣接する床外セルへ外壁候補を配置し、内部廊下や居室を塞がない。外部出入口候補の二幅・二高さを開口。中庭を実際の外部避難出口として認証しない。
  - 用途別外観リズム: 木質住宅、縦ガラスホテル、バルコニー帯集合住宅、ガラス面オフィス、石とガラス図書館。屋根と外壁の用途別スタイルは抽象ラベルであり実Minecraft材質を認証していない。
  - 内部: すべての室に用途別の小さな家具・設備プレースホルダーを配置。入口から室内の残存空きセルへの経路接続を監査。実家具と詳細内装の完成ではない。
  - 階段: B103の複数階段コアと各階廊下が隣接するコア境界の着地点を抽出し、上下階の仮想リンクを生成。Minecraftの実階段・勾配・手すり・踊り場・安全な上下移動を認証しない。
  - auditB105: 屋根キャップの欠損、外装の誤侵入、室内家具の通路妨害、出口の閉塞、階段接点の欠損、ボクセル占有競合を検査。
  - drawB105Elevation: テキスト立面で壁 #、窓 W、出口 E を区別。人間による美的検証や3Dレンダリングではない。
- source/parallel/b105/main/compile-b105.mjs: 5用途×3案/66仮想階を再生成して比較。屋根・窓・家具・階段接点と3D衝突の数を集計。
- source/parallel/b105/main/compile-b105.test.mjs: 新規30テスト（既存382件と合わせて412件）。
- scripts/verify-b105-safety.mjs: 未承認候補保護、建物全体IRの安全性、旧9ゲートの施工禁止。
- .github/workflows/qa.yml: GitHub Actions自動検証。

## 限界
屋根は雨仕舞・排水・荷重支持を持たない抽象的なセルキャップ。窓は透過やBlockState未検証。家具は用途別1セル占有で実形状・材質未実装。階段着地点は概念グラフでありMinecraft実移動不可。地形接続を確認した出入口ではない。外観の美しさは人間が3Dでまだ確認していない。建物全体モデル＝完成建築ではない。

## 次の優先機能
B106で実Minecraft Educationのバージョン固定・読み取り専用BlockState辞書と、実ドア/階段/窓との互換性照合を検討。同時に生成IRに忠実な3D外観・屋内レビューを導入し、建物全体の完成品質を改善する。

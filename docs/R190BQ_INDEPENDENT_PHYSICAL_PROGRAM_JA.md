## 発見した監査上の抜け
R190-BOのBN/R4はモデル申告の空間・到達閾値に対して技術代理検査を実施する。しかし、同じモデル自身が宣言した部屋名や階数説明だけを使って自由な日本語依頼への忠実性を証明することはできない。
例えば「高層ビル」を要求されても、二層の空間が成立しただけでオフィス・レストランがあるとは言えない。

## 作業内容
- `source/ai/r190bq-independent-physical-program.mjs` を追加。厳密B143の最終ボクセルを再走査して、モデル申告の各空間ごとに実支持床セル、実空気セル、閉塞、立脚Y、面積、空気容積を集計する。
- すべて原回答SHA・原依頼SHA・派生geometry SHA・モデル出所と結び付け、`PHYSICAL_PROGRAM_REVIEW.json`に記録する。ソース/モデル原文に変更は加えない。
- R190-BPの`REVIEW.html`へ、立脚高さと用途宣言（自己申告であることを明示）、実床・空気の対応表を表示。
- BMの元高層ビル依頼が**完全に同じbytes-SHA**である場合だけ、1/2階の大広間、3階以上のオフィス、最上階付近のレストラン、規模感、上下動線の独立人間審査項目を作成。別の未知用途へ高層ビルのテンプレートや判定を押し付けない。
- BM原依頼で実立脚階が3種未満なら`HOLD_MISSING_THIRD_LEVEL`。3種以上でも構造の必要条件だけで十分条件ではなく、用途合格・美術合格にはしない。
- 真正B143のない無効原回答では独立監査成果を捏造しない。
- 既存のBO CIに合成2層の正の物理計測、同じ2層をBM依頼へ紐づけた負例、無効原回答の負例の3件を追加。

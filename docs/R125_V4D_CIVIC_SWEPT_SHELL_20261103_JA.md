# V4D 第三案 — 双殻の傾斜屋根・公共軸を同時著作する汎用SOURCE研究

2026-11-03 JST。既存START_HERE、11月3日完全統合正本、憲章、戦略v2を継承。初回V4Dと第二案の**正式ART REJECT**を変更しない。

## 意図と前工程からの根本的な変更

過去2案は、最初に直方体の主棟を置き、後から一部分をCUTして大広間のように見せる方法だった。今回の第三案は**最初から**中央の公開歩行軸と、左右の傾斜構造外郭・屋内用途床を異なるSOURCE要素として一体著作する。屋根に少し穴を開けたり色だけ変える経路ではない。

`source/ai/r125-v4d-civic-swept-shell.mjs`：短いAUTHOR意味IRに3つの空間bayとそれぞれの中心軸位置・左右建物幅・左右独立の高低屋根値・空間用途を指定する。さらに主入口・東西の利用可能な屋内翼への実開口2つ・高窓2系統を指定する。HOSTは用途名から完成建物を選ばず、定められた幾何・真正B143ビーム屋根／傾斜壁／床／開口と、証明可能なSOURCE空間/通行を生成する。

- 屋根と外壁はB143実 `beam` をZ方向に密接反復して構成。平屋根の矩形BOXを後から小切除したものではない。正面からも左右非対称勾配が読めることを狙う。
- 著作された各bayの軸中心を横方向に少しずつ移動させ、中央を12ブロック幅の実通行可能な公開空気空間とし、両側を傾斜屋根で覆った利用用途の翼にする。入口と東西翼は最終B143で2幅SOURCE経路を監査する。
- 入口前の広場、正しい壁の切除、真正ガラスも同時に変換。原屋根の構造・雨仕舞・実ゲーム物理は保証しない。

## 検証手段

合成AUTHOR試験は1例のみ。**実Qwen/Gemmaの新回答ではない**。Node厳格正負テスト、真正B143の `verifyCompiled`、屋根の左右の高低双方の物理ボクセル、中央空気の全高にわたる非占有、2幅支持床、入口起点の左右用途翼への到達、真のガラスを検証。安全出力は `NOT_PREPARED`、9 BLOCKED、BuildPlan空、WorldWrites0。

真正B143の旧第二案と第三案は、単一の `index.html` 回転3Dと同一縮尺の上面SVG、監査JSONに出力する。GitHub Actionsから一つのArtifactにまとめる。**新CI完走前はSOURCE PASSを認定せず、取得した真正3Dの独立美術審査前はARTを認定しない。**

## 境界と次判断

現段階は単層、軸に沿う3区間、厚みのある直線ビームの積層。Minecraftでの建築用途の完備・構造・ゲーム内歩行・完全な美術品質は未認定。屋根が大きく変わっても用途と公共空間の品質がまだ弱ければ**ART REJECT**する。CIやSHAだけで美術合格に昇格しない。

1. **Exactly one model request**, max 300 seconds by default. No hidden retries, extra plan, full 12+4 benchmark or Minecraft world operations. Qwen still authors ALL geometry; no fixed template.

4. New `source/ai/b198u-bounds-only-repair.mjs` handles ONLY **undersized declared B143 bounds** where a positive model-authored domain lies outside the declared width/height/depth. Original B143 upper bounds, 500000-volume budget and exact 3D compiler guards remain mandatory.

If any shape touches negative coordinates, the increased dimensions violate axis/volume caps, a source element is malformed/unknown or validation fails for another reason, **do not auto-repair or invent a different building**. Return honest compiler HOLD. Original model response remains accessible for manual/Chat analysis.
6. SHA provenance before/after and model-authored element-array SHA prove exactly what was changed. Any corrected candidate still requires an independently valid B143 compile, source topology critique, viewer and human architectural review.

### Offline replay, without starting Ollama

The Windows script now supports `-Mode ReplayLatest`. It chooses the newest saved B198U original candidate under `Documents/MinecraftAIBuilder-B198M` and runs deterministic B143 source validation, geometric bounds safety and 3D reviewer. It **does not read installed Ollama models**, query API tags, or call a model server. It does download its own versioned GitHub source ZIP unless `-SourceDirectory` explicitly references a local checkout; this is a script/source download, not AI inference.

Optional direct use of a previously captured file:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Mode ReplayLatest -ReplaySourceFile 'C:\path\to\B198U_ORIGINAL_MODEL_RESPONSE.txt'
```

Result: `B198U_UPLOAD_THIS_REPLAY.zip` contains repaired candidate, independent compiler/HOLD evidence, and a 3D viewer **if and only if** the original model source passed B143. The replay records **zero** local model calls. A source generated by the real model is not re-labeled as an independently authenticated provider during offline replay.

# B198Z-R74 — 建築動線3方針 × 6軸の独立した人間比較審査票

基準日：2026-10-22 JST。Draft PR #128。R73 Windows/Ubuntu Node24 CI PASS後の工程。

## 背景
R70〜R72は原本の最終概念ボクセルから低層候補・到達不能な上層・最近傍の構造と空洞を正直に可視化した。R73は3方向を並べたが、実際の人間の比較結果や根拠を一定の形式で記録する場所がなかった。R74では、機械が美術を採点するのではなく、人間の審査を明確に分離した帳票を追加する。

## 同条件で比較する6軸
1. 要求された公共利用・上層施設の機能
2. 支持床、階段、踊り場、頭上クリアランス
3. 元の巨大アトリウム・内部都市級空洞
4. 主要屋根・外殻のシルエットと建築質量
5. 実Minecraft Educationの移動・当たり判定
6. 未来的な美術表現と内外構成の一体感

R73の(1)支持床・踊り場を軸に上下動線を検討、(2)外周・側翼経由を検討、(3)独立施設としての意図と用途を確認、のそれぞれに6軸を設ける。各軸は「未審査」「証拠不足」「懸念」「追加検討に値する」の4段階。いずれも合格判定ではない。

## 実装と操作
- `scripts/b198zr74-human-option-review-worksheet.mjs` が、元原本SHA＋最終B143 geometry SHAを持つR70→R71→R72→R73を原本から再計算し、元資料に紐づいた未記入の比較票を作る。モデルの自己宣言した入口・部屋・経路は利用しない。
- R60の1回ZIPレビューで、`R74_HUMAN_OPTION_REVIEW_SHEET.html`（印刷・手書き用）と `R74_HUMAN_COMPARISON_BLANK.json`（編集可能な未記入テンプレート）を生成し、R60_INDEXから開けるようにする。R72の実ボクセル断面、R73の方針説明へリンクする。
- HTMLはオフラインかつJavaScript無し。紙へのチェックは自動保存されない。JSONテンプレートのユーザー追記は元の生成証拠に上書きせず別ファイルとして管理する。
- `inspectR74HumanDraft()` は提出されたJSONの原本識別子・固定された比較対象・6軸の選択値を検証し、未記入/一部記入/全記入の「自己申告上の完成度」のみ返す。**人間の本人認証、実機歩行、独立した美術合格、改修承認、モデル推論承認は判定できず、すべてfalseを維持する。**
- R62の未来限定の設計指示は、原本と一致した未記入のR74だけを証拠として扱い、独立審査の4項目をNOT_REVIEWEDのまま保持。回答済みシートでこのゲートを迂回できない。

## テスト
分断された上層、入口候補HOLD、中実建物、候補なし、自己宣言spatialPlanの偽装、R73・R74改ざん、すべて良いと申告したシートでも認証不可、部分的な手動入力、ファイル上書き防止、R60/R62結合を既存Windows/Ubuntu Node24 CIへ追加。新ワークフロー作成なし。

## 絶対的な安全境界
R74はQwenを呼ばず、Minecraft Educationにも接続せず、ジオメトリとワールドを書き換えない。`readiness=NOT_PREPARED`, `constructionApproved=false`, `executionAllowed=false`, 施工ゲート9件BLOCKED, `BuildPlan.operations=[]`, `modelCalls=0`, `worldContacts/Reads/Writes=0` を維持。Draft PR #128は開いたまま。CI PASSは帳票・証拠の検証成功であり、生成された建築の美術品質向上の証明ではない。

## 次段階への条件

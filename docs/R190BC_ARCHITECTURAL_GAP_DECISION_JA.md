## 4. R190-BCにおける設計上の決定

**新しい合成形態の大量作成、見た目だけの斜材追加、検査項目の無条件増設をしない。**

次の少数案・同一課題比較に限定する。

1. **用途→空間体験→建築断面→質量/空洞/支持→真正B143**という設計順序をモデルに明示する。主要空間・人の視線・支持断面が形の起点。用途を最後に箱へ押し込まない。
2. 実Qwen/Gemmaの独立設計能力と、ホストの幾何表現/投影能力を別々に診断する。既存の**直接B143モデル出力経路**と**意味IR→ホスト幾何経路**を混同せず、同じ要求を入力した事実が取得できる場合にのみ公正に比較する。無許可の新規推論はしない。
3. 最初に既存保存原文を完全無推論で検査し、「形式不正」「意味/用途の欠落」「形状が表せない」「立体の不成立」「美術の弱さ」を切り分ける。実ソースが無効ならモデル成功として参考3Dを補修生成しない。
4. B143で表現可能な質量・空洞・支持・空間断面を**作者自身**に定義させる方式から試す。B143自体の限界が具体的な必要形状で確認されるまでプリミティブ追加をしない。固定建築類型を新しい標準にしない。
5. 次回の試作候補は**最大2案**。全く異なる空間構成思想に限り比較する。既存のAT/AVの屋根と列柱を装飾し直すだけの案は作らない。

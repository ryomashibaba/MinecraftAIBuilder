# R190-AZ — モデルが自称する機能と真正B143の照合を1つにする

R190-AYによる保存済みの山間公共図書館案は、最初のB143コンパイル以前に部材宣言の整合を欠いていた。書式修正と建築成立は別の問題である。R190-AZは新しい合成建築を作らず、今後いつか**モデルが本当に有効な独自B143設計を返した場合**の審査を先に実装する。今回のプロバイダー呼び出し0。

## 検証の段階
1. 元回答のバイトSHA256を照合。モデル由来や原文内容をホストで捏造・修復しない。構文・B143として不正なら即HOLD、実3Dも実歩行も主張しない。これはR190-AAの保存済み1件では正しい結果。
2. 有効なB143なら、真正コンパイラを使い、結果をverifyCompiledで独立再検査。作者自身のCUTに対して、CUTのボクセル削除数（0か否か）を計測する。単に名前が吹き抜けでも、何も削っていなければ厳しいHOLD。
3. モデル自身のprotectedVoids（id・origin・size・maxOccupiedCells）に宣言された全座標が空かを最終ボクセルで計測。屋根まで開いているかは別問題で、絶対に『外部開放認定』にしない。
4. モデル宣言のentranceとdestinationを、支持床の上に二段の頭上空気があるスタンド位置として検証し、実ボクセルの4近傍と高低差±1の保守的なBFSで道順・必要ステップ数を検査。階段のプレイヤー挙動や実Minecraftでの移動を認定しない。
5. モデル宣言のfunctionalZonesについて、前工程R190-Tが計算する支持立脚セルと入口到達セルの数を照合。declared zonesが名前どおりの部屋か、実際に展示・書庫を果たせるかは未認証。
6. 一通り幾何の自己申告がSOURCE上成立しても、ステータスは SOURCE_MODEL_CLAIMS_PHYSICAL_PROXIES_PASS_ART_HOLD に限定する。人間の美術審査、独創性、要求意味、構造工学、実歩行を認証しない。

## 研究方法・安全
`scripts/r190az-physical-claims.mjs` は元回答の読み取り専用で、モデルの建築類型や形状を選ばない。`scripts/r190az-physical-claims.test.mjs` は既存の無効な実モデル原回答を必ずHOLDし、別の正しい**合成SOURCE**で実CUT・屋内空気・到達・モデル申告値の成立を検証する。CUTが空振りしたり、吹抜け内に新しいソリッドを後置きしたり、行先を埋めるとHOLDにする。合成はモデル実能力の証明ではない。

入力の実原文は再発行しない。CIアーティファクトはREAD_ONLY_PHYSICAL_CLAIMS.jsonとSTATUS_JA.txtの派生レポートのみ。新規モデル実験は別途承認、世界接触0・施工0、NOT_PREPARED、9 BLOCKED、BuildPlan空、正式美術採用0、PR #128未マージ。

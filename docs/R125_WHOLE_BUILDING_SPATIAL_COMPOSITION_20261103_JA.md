# MinecraftAIBuilder — 建物全体の設計能力を優先（2026-11-03 JST）

## 事実と根本原因
ユーザー実Qwenによる新規平屋店舗は897ボクセル・入口から2用途室へのSOURCE到達を確認。一方で機能什器のSOURCE到達証拠は0件、現物はほぼ矩形の単純な店舗。Minecraft実施工は未実施、ART HOLD。従来のR125は各階2分割と限定された外形・屋根表現が基本で、建築全体の設計自由度を狭めている。個別の窓・屋根装飾の改修では根本原因を解消しない。

## 今回の実装：別系統・オプトイン
source/ai/r125-spatial-composition.mjs は特定建物テンプレートではなく、モデル/設計者が指定した2〜5室の用途・寸法・接続相手・相対位置・屋根高さを、共通HOSTが実壁、開口、屋根、床へ確定変換する接続木の最初の実装。既存B143を使用、真正ボクセルと2幅SOURCE経路で不成立の接続・重なり・偽の外部入口をHOLDする。3種類の配置をSOURCE回帰で独立検査する。

これは大きな建築構成の研究開始であって、独創的な美術の完成、曲面、家具、設備、階段、実Qwenの新モデル回答、Minecraft施工の合格を意味しない。全てART HOLD/NOT_TESTEDを維持。

## これからの能力目標
1. 一棟の修正を繰り返さず、住宅・入口付き店舗・小研究施設で、実モデルが異なる空間の接続・外形・高さを自主的に設計できるか評価する。合成テストを実モデル成功と偽らない。
2. 4方向/斜視/入口/内部の真正3Dを人間が評価する。箱に小さな装飾を増やしただけなら採用しない。
3. 全体構成が成立した候補に、モデル指定機能と共通什器・床・採光・階段を一体的に接続。特定店舗専用のレシピは増やさない。
4. 最も良い候補だけ既存の厳格なEducationワールド識別・バックアップ・材料・施工ゲートに送る。既存研究施設の再施工は禁止。

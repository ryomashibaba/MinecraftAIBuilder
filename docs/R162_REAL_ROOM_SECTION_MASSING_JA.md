# R162 — 空間構成から実際の外形を作る（同条件の真正B143比較）

**現時点の目的**：R161で「間取りは違うのに上部の外形が全て同じ」と実証された問題を一般的な方法で解く。住宅・店舗・研究所に固有の外観テンプレートを作らない。

## 設計境界
- 新しい型を増やすことを成果とせず、既存R160 `architecture.spatialTopology` とR134の `layout.spaces[].weight`、本物の部屋範囲を入力に使う。Qwenが屋根座標や小部材を出す必要はない。
- `source/ai/r162-room-section-massing.mjs` は、3つの室ごとにR149の既存低天井を**実際にCUT**し、元壁の上に囲いの壁を立て、高さ8/9/10に屋根を作る。部屋の物理配置に追従するため、中央通路と片側ギャラリーでは**上部実ジオメトリの位置も変わる**。これは居室上部の利用可能な空間を伴い、単なる屋根上の箱ではない。高さは短い意味IRの相対重みに基づく（重みが同点なら安定順序）。座標はホスト生成器のみが決定。
- R162は「実モデルの発想」ではなく「ホストがモデルの意味設計を正しく外殻に変換する能力」。新規LLM推論を実施しない。既存 `--architecture topology` で選択されたときのみ新規高室を適用し、他のモードと原本を維持。
- 下部y<=5の実ボクセルを材質ごと不変と証明。屋根下の空気、屋根上の実セル、全室および全設備への2幅ソース経路を再計算。3室、R149経路が成立しない場合、敷地寸法不足、元ソース改変時にはHOLD。強制補修なし。

## R162比較物
`scripts/r162-room-section-comparison.mjs` はR161と同一のプログラムで中央／西／東それぞれ「R149共通外装（before）」と「R162実高室+R150設備（after）」計6つのインタラクティブB143シーンを作る。比較HTMLと元のB143 JSON、幾何ハッシュ、各室の実高天井空洞の範囲、設備アクセスQAを保存する。GitHub Actions既存ワークフローのArtifact名 `R162-REAL-ROOM-SECTION-AND-EXTERIOR-3D-COMPARISON`。アーカイブから `index.html` を開いて実3Dを評価できる。

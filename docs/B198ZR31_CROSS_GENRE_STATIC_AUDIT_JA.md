# B198Z-R31 — R30指示の異ジャンル適用性と矛盾検査

## 目的と結論の上限

R30の汎用空間先行ガイドが、単一の図書館やR25原本の形状に過度に依存していないかを、実モデルを使わずに検査する。

**この工程で検証するのは「指示の文字列に必要な概念があるか」「一部の明示的な矛盾がないか」だけ**。
架空の依頼をQwenに解かせたわけではない。実際に異ジャンルの建物を生成できるか、意匠の自由度が本当に保たれるか、全ての矛盾が存在しないかは**未確認**。

## 6ジャンルの仮想ブリーフ

| 仮想ジャンル | 想定する自由度 |
|---|---|
| 多層図書館 | 高層・非対称・階段分岐 |
| 地下博物館 | 中庭・展示室・環状動線 |
| 高架商業施設 | 橋状の通路・枝分かれ |
| 環状天文台 | 円形・ループ動線 |
| 浮遊研究基地 | 空中の離れた質量と接続塔 |
| 彫刻的美術館 | 曲面・不規則形状・複数経路 |

全ジャンルに共通して、支持床・頭上空間・利用可能な領域・入口開口の整合・目的地への到達・厳格B143材質規則を要求する。経路本数、建物形状、寸法、配置は指定しない。

## 監査方式

`source/ai/b198zr31-cross-genre-static-audit.mjs`

- R30の10項目を文字列で照合
- 6仮想ブリーフそれぞれに、同じ一般的な安全・幾何契約を適用
- 単一路線の強制、ループ禁止、R25の歴史的入口座標、固定テンプレート強制、CUTへの材質強制、モデル自己認証の一部を正規表現で検出
- 意図的に指示を壊す合成テストで、監査がHOLDを出すことを確認
- R30、R28、R21、R11は一切書き換えない
- R25実Qwen原本とR27診断JSONも変更しない

### 静的監査の限界

文字列一致は意味理解ではない。矛盾する指示が巧妙な言い回しで書かれていれば見逃す可能性がある。
6ジャンルは実際のQwen応答やボクセルではなく、適用性の検討対象となる仮想依頼である。
この工程で品質PASSを認定してはいけない。

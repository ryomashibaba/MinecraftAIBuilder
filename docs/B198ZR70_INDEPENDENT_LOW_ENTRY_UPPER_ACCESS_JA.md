# B198Z-R70 — 外側から上層空間への暫定的なアクセス検証

2026-10-22 JST。MinecraftAIBuilder Draft PR #128 継続。R69両OS CI PASSを確認。これは実Qwen生成／施工ではなくオフラインの検査。

## 目的と推論不能なもの
R69は支持床候補間の上下移動可能性を調べたが、『外部から入って上層施設までたどり着く』という実利用観点までは確認していない。R70ではAIが自己申告したentranceやdestinationsを使用せず、厳格B143最終ボクセルから低層の仮入口候補を推定して同じ抽象移動グラフで探索する。

## 新アルゴリズム
- 元原本SHA・B143最終概念ボクセルSHAの再照合が必須。原本編集・モデル再推論・Minecraft接続なし。
- 支持床が下にあり足元＋頭上1セルが空いた全位置を測定し、最も低い足元yとその1セル上のバンドのみを入口の探索対象とする。真の地上階・道路の高さは不明。
- XZ方向のいずれかのまっすぐなレイで、設計グリッド境界まで足＋頭の2セルが遮断されない地点を低層候補とする。線形スイープを使い、立ち位置ごとに個別長距離レイを投げない。
- 候補群からR3/R64と同型の1セル高さ移動制約つき支持床抽象グラフを幅優先探索。連結到達した全支持床、各高さの支持床、最も高い足元、初期地点からの最大距離などを算出。
- 『上層』は**最も低い支持床y+3以上**という検査上の基準であり、展望ラウンジなど意味的用途は認定しない。
- 入口候補がないとき、到達不能と誤って断定せず、到達数をnullとしてHOLD。候補があっても、外部の歩行路・扉・Minecraft衝突形状・歩行操作が可能とは証明しない。窓のような開口でもレイが通るため偽の入口候補となり得る。

## R60/R62との接続
- R60オフラインレビューでB143がコンパイル合格した場合のみ、R70 JSON・HTMLを追加してR60_INDEX.htmlから人間が閲覧できるようにする。HOLD原本では生成しない。
- R62の未実行の次回設計指示へ、到達できない上層床、低層候補不足などの注意点を追加する。R70 JSONの値を原本から完全再計算して照合し、R64/R69の支持床数との一致も検査。原本・履歴の書き換え不可。
- 中庭・アトリウム・大屋根・独立棟・建築的スケールを壊してまでアルゴリズムに合わせる指示にしない。凍結c01の4項目は引き続き人間審査未実施。

# B102 — 汎用の条件付き間取り生成と仮想3D断面監査（Minecraft Education優先）

## 目的
B101までは既存の居室を再割当てしているだけだった。B102では、**必要室数・用途・最小有効面積に合わせて、居室の位置と寸法そのものを生成**する。

## 新しいコード
- `source/parallel/b102/main/b102-synthesis-voxels.mjs`
  - `synthesizeRooms`: B100の5用途15候補の床形状と2セル通路を読取専用で利用。部屋の矩形と壁厚1セルを探索し、部屋間・コア・通路・床欠けを避ける。面積制約は**壁を除いた室内面積** `(width-2)*(depth-2)` で評価。必要室数が置けない場合は明示的に `HARD_REQUIREMENTS_UNMET` と不足数を返す。Greedyな探索なので解が存在しても発見できないことはある。
  - `voxelAudit`: 階ごとのローカルy=0床、y=1..3空気／壁、y=4天井を含む概念的な疎3Dセル監査。入口は壁の角を避け、廊下に接する1セル幅×高さ2セルの空き領域と、内側の高さ2セルの空き空間を照合。**部屋が異なれば同じ材料の重複セルでも衝突**とみなす。
- `source/parallel/b102/main/compile-b102.mjs`: 15案を同一の生成器・3D監査で比較する再現可能な報告。
- `source/parallel/b102/main/compile-b102.test.mjs`: B102専用35テスト。
- `scripts/verify-b102-safety.mjs`: 安全状態・元の296未承認＋18保留室・衝突・入口空間・ブロック命令禁止を再検査。
- `.github/workflows/qa.yml`: B92〜B102の322件＋凍結整合・施工禁止検査。

## 今回のオフライン検証で成立した数値
- 一戸建て・ホテル・集合住宅・オフィス・図書館の5用途×3案＝15案、合計66仮想階。
- 合計279の**新しい概念的な居室矩形**を、各用途の要求された室数・有効面積に合わせて提案。
- 279の概念的な壁開口で高さ2セルの空気領域を確認。3Dセルの材料／占有衝突0件。
- これは**元のB100 381室の改造ではない**。B100原本は読取専用でありB101も保護。
- 数字は実機施工、ドアの開閉、階段、避難出口や完成室を意味しない。

## 重要な限界
- B100の**建物全体形状・共用回廊・単一予約コアの位置は固定入力**。複数コア再設計、現実的な出口設計、建物全体の再合成には未到達。
- ドア開口は**空気セルの候補**でありMinecraft Educationの現実のドアブロック、向き、開閉、材質互換性は未検証。
- 頭上2セル空間はローカル断面だけ。屋根/支持柱/階段/上下階導線/敷地外への脱出は未検証。
- 部屋の建具・家具・窓・内装・外装・安全な自動施工は未完成。従来の296室候補や18室保留の承認もしていない。
- 数字の高い候補をそのまま建築許可とせず、視覚的品質、用途への忠実さ、建築多様性も今後の重要な評価対象とする。

## 安全条件・施工規制
Education版を優先し、Java版は将来拡張。9ゲートBLOCKED、NOT_PREPARED、BuildPlan.operations=[]、commandCount=0、worldCoordinates=null、worldContacts=0。
新たなMinecraft世界へのブロック施工やオンライン検証は行っていない。

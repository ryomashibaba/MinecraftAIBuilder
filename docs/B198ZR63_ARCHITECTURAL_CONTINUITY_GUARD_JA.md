# B198Z-R63 — 建築構想の損失監視と保存原本どうしの改訂比較

2026-10-21 JST。既存Draft PR #128 / R62後続。追加の実Qwen推論・Minecraft接続／読取／施工なし。

## 解決する問題
R62は検証から改善指示を作れるが、その指示に従った新しい案が、元案の大規模な空間構成・立体的な高さ・使用空間・魅力を失う可能性がある。R63は人間が審査できる比較資料を、書き換え不可能な保存原本に基づいて作る。

## 改訂比較の根拠
- scripts/b198zr63-architectural-continuity-watch.mjs が、元案と改訂案の原本SHAを照合し、両案を別々にB143コンパイルする。
- 両案ともB143 PASSなら、最終概念ボクセル数、占有XZ列数、建築の高さ、足元の支持床と頭上2セルの空気を持つ単一站立候補を比較する。これらはMinecraftで実際に歩ける証明ではない。
- 減少が大きいときは人間による確認が必要なリスクとして表示。自動不合格、自動美容評価、固定された最小規模・形状禁止規則にはしない。縮小や大胆な形態変化も許容する。
- boundsが一致する場合のみ同じローカル格子上で占有セルの重なりを数える。これは二つの建築物が同じ構想・座標フレームにある証明ではない。
- 元案または改訂案がB143 HOLDなら幾何の変化量を捏造せず、比較は保留する。特に過去R48のようなB143未コンパイル原本を0セルとみなさない。
- 凍結c01日本語依頼の4要件をモデル宣言とは独立した未審査の人間確認項目として保持。幾何の増加も減少も品質PASSではない。

# MinecraftAIBuilder B198Z-R73 — 建築の個性を守るための動線方針比較

基準日：2026-10-22 JST。Draft PR #128継続。R72 Windows/Ubuntu の既存CIは両方成功。

## 解くべき課題
R71/R72で孤立した上層床と既存の固体・大空洞を確認できた。ただし、その2点を結ぶ最短工事だけでは外観や内部都市・アトリウムの価値を壊すおそれがある。R73は最短工事案を自動設計せず、**同じ最終ボクセルに根拠を持つ3系統の人間の検討方向**を比較する。

## 選択肢
- 既存の床・躯体を確認しながら上下階を結ぶ可能性を探る：支持床・踊り場・実Minecraft衝突と十分な実利用性の検証が不可欠。巨大吹き抜けを床で埋めない。
- 中央空洞を横断せず、外周・側翼に沿う可能性を検討する：外形シルエット、接合、安全性、長い回り道の影響を確認。周囲に空いた経路が実在するとは主張しない。
- 分棟・上層施設の設計意図と用途を確認する：意図的な独立性は維持してよいが、凍結した日本語要求の一般利用機能を無断で省略しない。

## 実装と証拠境界
- `scripts/b198zr73-preserve-concept-circulation-comparison.mjs` により原本SHA/B143 geometry SHA、R70・R71・R72証拠を原本から再計算・照合。R72保存JSON改ざん、古い幾何、B143非合格を拒否。
- 最大3件のR72分断領域に3方針を併記。各方針は実現可能性、施工費、推奨順位、実際の経路長を推定しない。人間の設計審査を `NOT_REVIEWED` のまま保持し、採用選択なし。各案を比較する際の保存条件・検証事項を区別。
- B143合格時はR60 ZIPレビューで `R73_HUMAN_CIRCULATION_OPTIONS.json` と `R73_PRESERVE_ARCHITECTURE_ALTERNATIVES.html` を作成し、R60_INDEX.htmlからR72実ボクセル断面とともに閲覧可能。B143 HOLD時は検査値を捏造しない。
- R62の未来限定の設計指示候補へR73を原本から再計算して照合した後にだけ反映。誰も選択していない方針を採択済みと扱わない。

# B108 — Chromium実表示検証、屋根シルエット・階間外壁・レビューUIの改善

## 発見した問題

B107のGitHub Actions ZIP内の実際のHTMLを取得し、ローカルChromiumで一戸建て/ホテル/集合住宅/オフィス/図書館をレンダリングして確認した。15案切替、表示は機能したが、大きな見た目上の課題があった。

- **各階の上下の黒い隙間**：B105の外壁は一階あたり3セル高さの概念パネルしか持たず、階高5セルと合っていない。B107のレビューでは格子の隙間が目立つ。
- **屋根が単なる平板に見える**：B107の立体屋根は低く、屋根の棟や端部が読み取りにくい。
- **外観に内部の開発ガイド（青/緑/紫）が重なって見苦しい**：表示の初期状態が構造確認用のまま。
- **3D重なり順が視点の実際の深度と一致していない**：旧深度ソートは回転の角度と高さを正しく用いていない。
- **状態表示の分母が旧B106のセル数のまま**：B107の追加ボックスが加算されず「表示数が合計数を上回る」というUIバグ。

## 実装

- b108-fidelity.mjs：実B106の外壁候補セルに対応して、下端と上端の見た目用の連続パネルを生成。出入口空気セルに新しい外壁を配置しない。実B105の屋根キャップへ用途別の屋根高さ・輪郭を加える。5用途それぞれ屋根形状が異なる。**全ての追加造形は概念の小数3D形状で、実Minecraftの建材ではない**。
- compile-b108.mjs：既存B107の自己完結型HTMLを書き換えて、外観と内部で適切なレイヤー表示を行う。カメラ深度に基づく描画順、面ごとの陰影、正しい統計分母と描画時間表示を追加。B107/B106の原本を変更しない。
- compile-b108.test.mjs：20件の数値・ソース根拠・安全・ブラウザ用HTMLの構文チェック。総492件。
- verify-b108-browser.mjs：Playwright Core＋実Chromeを使って15案の全表示、色付きキャンバス実描画、外観/内部切替、回転、ズーム、モバイル幅、JavaScriptエラー0・外部リクエスト0を検証。5用途と室内のスクリーンショットをGitHub Actionsの成果物として保存。**本工程は実ブラウザー検証を含む**。
- verify-b108-safety.mjs：9ゲートと凍結原本、実施工・実BlockState認証0を検証。
- .github/workflows/qa.yml：新しいB108プレビュー/QAスクリーンショット/レポートをActionsに保存。

## 視覚評価の限界

形がより建築らしくなっても、Minecraft Education 26.3で利用可能な実ブロック構造・階段動作・屋根の防水/耐荷重・人間が美しいと思うかどうかは未認証。スクリーンショットと検査数値を得て、次の改善に活用する段階。外観の見た目と現実に施工可能な構造を混同しない。

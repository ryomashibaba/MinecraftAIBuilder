## なぜ不採用か：BY→BZ→CA→CB→CCで共通化した失敗
- BY：見た目だけ連続して見える巨大側壁（閉輪郭）。
- BZ：自由な立体パッチを付け合わせても断片的な巨大板になった。
- CA：内部容積を追加したが平行2塔・段状の太塔に戻り、上階移動も存在しなかった。
- CB：階段SOURCEを明示したが主殻は単純な多角塔と横帯に見えた。
- CC：3D自由形状と大切除体積を実現しても、今度は意味の弱い巨大な有機的塊の結合になり、レストランの室内量が消えた。

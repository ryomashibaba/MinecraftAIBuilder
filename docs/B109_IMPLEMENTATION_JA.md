# B109 — 外装を連続面にする・屋根と窓の見え方を改善・描画量の削減

## 基準となる実表示
B108（main `155303800bb9`）のChromium画像では、各セルが1個の小さな立体として塗り分けられ、屋根の瓦が細かく突起状に見えたり、窓のガラスが外壁の間から目立ちにくい問題が残っていた。一方B108では15案すべてをChromeで確認し、外観/内部カットと操作の正常性を検証している。

## 今回の変更
- `source/parallel/b109/main/b109-surface-model.mjs`：**B106/B108の1セルごとの元の座標を変えず**、同一高さの連続する外壁・階間帯・屋根・窓の集合を矩形の視覚面へ統合する。全セルへの厳密な逆展開監査とSHA256改ざん検出を追加。各用途で素材色と屋根高プロファイルを差別化する。
- 旧B107の細い窓枠と小さな内側ガラス表示に代え、B105の窓候補セルの集合を覆う大きなガラス面とアクセント縁を表示する。**実ガラスブロックとしての施工可否やサイズを認証したものではない**。
- `source/parallel/b109/main/compile-b109.mjs`：B108が生成したHTMLを別ファイルへ変換。外観モードの既定表示は一体化した壁・屋根・窓、室内モードは旧B105/B107の室内ガイドを優先。15案を一度のHTMLで表示する。
- 元のB100–B108と凍結原本は変更しない。新規24件テスト（総516件予定）で欠損・重複・誤寸法・HTML JavaScript構文・原本保護を確認。
- `scripts/verify-b109-browser.mjs`：実Chromeで15案を開き、描画された画像と表示レイヤー、内部カット、視点変更、携帯画面を確認し、画像・QAレポートをActionsへ保存。
- `scripts/verify-b109-safety.mjs`：施工禁止・9ゲートを再確認。

## 工程の限界
B109は**閲覧表示とデータ検証の改善**。設計セルの圧縮表示であって、実Minecraft Educationの施工用BlockState、ドア・階段・家具・屋根・窓の物理実装ではない。屋根の荷重・防水、ガラスの透明性やサポート状況、美観の人間評価を認証していない。

## 継続方針
建物全体の見やすさをさらに上げたあと、Minecraft Education v26.3の実機・バージョン固定素材辞書と設置方向などの読み取り専用検査、3D階段の実移動可能形状の設計と内部完成へ進む。無承認のワールド操作は行わない。

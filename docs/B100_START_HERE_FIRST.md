# MinecraftAIBuilder B100 → B101 統合引継ぎ｜最初に読む

**正式対応の優先順位は Minecraft Education版 → 将来Java版。** 旧B99以前の全1,599ファイル、旧296室未承認候補、18保留室、本番Plannerを凍結保全。B100の生成器は、既存の集合住宅構造をコピーせず、**5用途×3案＝15種の独立新築仮想設計**を共通データ形式から生成する。

まず本書、`B100_MAIN_SUMMARY_JA.md`、`B100_QA_SUMMARY_JA.md`、`B100_RESTART_INSTRUCTIONS_JA.md`、`source/parallel/b100/main/b100-universal-design.mjs`、`compile-b100.mjs`、`B100_GENERIC_DESIGN_REPORT.json` を確認。

## B100範囲
- 構造IR: 階ごとのローカル床マスク、全階共通3×3コア予約、幅2セルの名目廊下、矩形の室容積、2セル連続の名目入口候補、敷地・階数・用途・様式・ハード制約。
- 一戸建て2階、ホテル5階、集合住宅6階、オフィス6階、図書館3階。それぞれ異なる平面形状3案。66仮想階、381概念室。
- 日本語パーサーは **ルールベースの試作**。定型の建物タイプ、階数、中庭、吹き抜け、セットバック、用途語を抽出する。自由文の意味理解を実証していない。未知用途は停止、勝手な用途推測は禁止。
- 形状多様性は壁材の差でなく床マスク全階のセル差率で評価。15案すべて異なる。
- 入口候補381件は3Dドアではなく、構造、階段、家具、日照、避難経路も未実装。**完成室0、施工承認0**。

## 必須安全条件
`readiness=NOT_PREPARED`、`constructionApproved=false`、`executionAllowed=false`、9 Gate `BLOCKED`、`BuildPlan.operations=[]`、`commandCount=0`、`worldCoordinates=null`、世界接続0、ブロック配置0。
**Minecraft Educationの本番ワールド、旧本番ブロック、旧ファイルを変更しない。** Java版コード・アダプターは現時点では実装しない。Educationの旧施工システムもB100コンセプトへ無条件で接続しない。

## B101の重要な焦点
- 居室の用途・数・必要面積を厳守し、部屋を配置できないときに未達を明示する制約モデル。
- 一般の住居・ホテル・公共施設で成立する複数コア・外部出口・上下階経路の証拠のモデル化。
- 実ブロックの床・壁・開口・ドア枠と2ブロック高さ・動線の検査。実施工禁止のままEducationの公式ブロック定義への読み取り専用変換を検討。
- 日本語指示の未解析条件を捨てない仕組み。未知条件は認証停止。
- 多用途の実3Dレビューと見た目品質の人間評価を重視。単なる部屋候補数の増加に偏らない。

全量ZIP保護チェックは `B100_ORIGINAL_FILE_PROTECTION.json` と `B100_INTEGRITY.json` に収録。

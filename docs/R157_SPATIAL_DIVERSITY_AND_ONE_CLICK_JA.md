# R157 — 実モデル未知用途3件を1回で検証し、見せかけの多様性を検出する

## R156からの技術的な不足
R156では原文やB143 SHA、部屋名・設備・素材の差が建築の差と誤認される可能性が残る。とくに**2件だけ同じ構造**、**屋根1種だけ変更**、**材料・名称の差だけ**を本当の用途別設計成功と扱わない。

## 対応
- 新規 `r157-comparative-review.mjs`: 既存R156成果の元モデルJSONを非破壊で読み、部屋のID・用途説明・タイトル・材料を除外した空間構成を独立比較。平面寸法/ゾーン数/面積配分/分割向き/入口位置/隣接グラフ/屋根輪郭/主従/到着空間を判定し、3組すべてを監査。元3Dのsource/geometry SHA一致も検出する。設計の違いは美術品質合格ではない。
- `R157_COMPARE.html`: 住宅・店舗・研究施設の本物のB143ビューアへのリンクと、存在する場合3Dの並列iframe。3D未生成は必ずHOLD表示。詳細 `R157_SPATIAL_AUDIT.json` を保存する。
- `RUN_R157_UNKNOWN_USE.cmd`：既存のWindowsリポジトリでダブルクリック。ブランチ・追跡差分検査→安全な`git pull --ff-only`→ローカルQwen `qwen3:14b` から**3回の新規推論を試行**→比較・監査→原文・B143を含む結果ZIPまで1操作。ユーザー作業を縮小。別のモデルはPowerShellで `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/r157-one-click-unknown-use.ps1 -Model gemma4:26b` 等で指定可能。
- 実行環境がモデルを動かせない場合、**モデル呼出し成功は主張しない**。既存QAのテストHTTPは実モデル証拠に含めない。原本を変更せず、モデル推論失敗時もZIPにある限り結果を残す。

## 継続方針
旧Qwen原本とDraft PR #128を保護し、mainにはマージしない。R156/R157の現時点での新規実モデル回答は未取得。CI通過は実Qwen/Gemmaの汎用設計・美術・実ワールド品質を証明しない。人間の現物3Dレビューが終わるまでART HOLD、9ゲートBLOCKED/NOT_PREPARED/空BuildPlan維持。実際のモデル比較が設計の同型収束を示したときは建物別の窓や屋根をさらに足さず、共通エンジンの空間構造の自由度を見直す。

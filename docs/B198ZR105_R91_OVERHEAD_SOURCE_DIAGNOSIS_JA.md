# B198Z-R105：右翼tier2の頭上衝突源を実三角形から特定

研究専用・2026-10-23 JST。R104両OS成功ログで、右翼tier2のR91床の未検出は0、頭上交差は1、床増設の改善は0と判明。**床を広げ続けるのは現在の重大問題を解消しない**。

## 今回の変更
- 独立のR104幾何・元R91現行床2面を保護。幅の張り出しピークを0.010／0.014／0.018（R104既定）／0.022／0.025で比較。
- それぞれ元の実メッシュ三角形を使ってR99/R101の頭上・横断・足元のRayを実行し、元の床の未検出が減り、頭上・横断の問題が増えず、元R104より床のRay証拠が悪くないもののみ候補とする。最大改善件数が同じなら小さい張り出しを優先。ただし美術や構造には昇格しない。
- 実際の右翼tier2頭上交差元の sourceKind、三角形番号、3D交点座標を証拠JSONとCIログに記録。屋根だったのか、R91に追加した手すり等だったのか、その場で原因を区別する。
- 既存R60レビュー内のR105証拠JSONと比較OBJを同じ保存フォルダに書き込む。R102/R104/R105の同一カメラ6視点表示。既存成果物上書きなし。
- 当初のR105実メッシュCIは確認待ちで、通路床/頭上修正が成功したとは主張しない。対象が屋根と判定された場合だけ屋根を、手すりの場合だけ手すりを次工程で検討する。

# B120 — 残り8出口の折返し階段・3D代理モデル一体探索（非施工）

B119の全15棟66階102階段の監査結果から、局所直線階段3D候補のない8出口を抽出する。これらの元の階段は動かさず、B120の変更は専用のDraft PRに限定する。

## 主な追加機能

- B114のAPARTMENT_V1で検討済みの「2段＋3段」「3段＋2段」の180°折返し階段を、**20マス（5×4）の局所占有枠**として汎用化。
- B114の符号付きボクセル変換を使い、4方向の回転、距離3以内の移設候補を調査。1本につき原則200通り。
- 階段本体の踏面・中間踊り場8マス・支持材・2ブロック高さの人体包絡を実際に再生成する。
- 元の階段・部屋・床・廊下・コア・B105壁や家具、他階段の3D支持材との衝突を検出し、接続できない候補を除外する。
- 上下の階の幅2廊下への概念的接続を確認し、床開口候補・踊り場の支持床を個別に審査する。
- 反例テスト8件、15棟/102階段/残り8出口の集計テスト5件、日本語Markdown・JSON・CSVを出力。

## 権限と制限

本工程の出力は、局所的な**設計代理形状の仮説**に過ぎない。実際のMinecraft Education階段BlockState・人体当たり判定・中間踊り場の実耐荷重・天井の施工形状などは未認証。仮候補が見つかってもB119の9件の元HOLDは解除しない。

`NOT_PREPARED`、施工9ゲート`BLOCKED`、`BuildPlan.operations=[]`、`worldContacts=0`を維持する。既存B100〜B119ソースやmainは書き換えず、Minecraftへの接続・施工、既存PRのマージは禁止。

# R163 — 実際の室に開く高窓・屋根の検証（2026-10-25）

## 問題と目標
R162で3つのトポロジーから実際に使える高室・異なる外形は生成できたが、新たな上部の壁に外側の開口がなく、日照や屋根の連続性を検証していなかった。屋根上の装飾・「ガラスっぽい部材」を増やすのではなく、実3Dが**外壁のガラス→室内空気**を直接つなぎ、かつ各室を屋根で覆うことを共通エンジンで成立させる。

## 具体実装
- `source/ai/r163-daylit-sections.mjs`：R162の3室実位置に合わせ、外壁（西/東/前/後）だけに各室1本の高い水平窓を実CUT＋glass ADD。内側の壁や共通ギャラリーに面する壁には窓を作らない。模型の作り物ではなく、ガラスの実セル・外の空気・内の空気を1セルずつ検証。ガラスは屋根の下で、旧下階、入口、全設備、支持床を壊さない。
- 実室の全床座標について、天井高6以上の連続した空間とその上に実屋根が存在することを検査。R162の基準と元ソースの全セル `y<=6` を材料ごと保存。R125の2幅ソース経路・設備到達を再検証。
- R160の `--architecture topology` パスには `R162高室→R150設備形状→R163外窓` を追加する。従来の他モードや保存Qwen原文は変更しない。LLMは窓のボクセル座標を生成しない。用途名で定型建築に分岐しない。
- `scripts/r163-daylight-comparison.mjs`：R162の同条件3案から変更前後6つの真正B143ブラウザシーン、元ソースと実ボクセル、独立監査JSON、同時比較index.htmlを生成。既存品質CIに追加したArtifacts `R163-REAL-ROOM-DAYLIGHT-AND-ROOF-3D-REVIEW` に保存。

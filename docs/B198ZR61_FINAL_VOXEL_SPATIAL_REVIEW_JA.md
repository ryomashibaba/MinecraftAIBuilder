# MinecraftAIBuilder B198Z-R61 — 最終ボクセルによる内部・動線の審査統合

基準：2026-10-21 JST。既存Draft PR #128 / R60の後続。新しい実Qwen推論とMinecraft操作は実施しない。

## 問題
R60は原本SHAで守られたB143最終概念3D（形式PASSの場合）とR51外接範囲図（形式HOLDの場合）を表示できるが、外形を見るだけでは図書館の入口・部屋・階段・吹き抜けが成立したとは言えない。

## R61の実装
- 既存R43の最終概念ボクセル検証を直接再利用する。固定設計テンプレートや新たな生成器は作らない。
- B143がPASSしてR7を作れた場合のみ、R43実ボクセル断面（入口、3目的地、3機能領域、2保護空洞まで）をR60の審査フォルダへ追加する。
- 断面は # が占有、o が支持床と頭上空間のある空気、. がその他の空気。E/D/Z/Vは注目点であって到達証明ではない。
- 空洞を埋め戻した後続ADD、閉塞された目的地、中実の機能領域を、元の原本を修正せずに検出した診断として示す。
- R43が空間計画の解析をHOLDした場合は断面の捏造をせず、モデル宣言を検証できない旨を表示する。
- R60_INDEX.html からR61の読みやすいHTMLと証拠JSONへ直接進める。R51未コンパイル図にはR61最終ボクセルというラベルを付けない。

## 独立性と承認
モデル自身のspatialPlanが設定した容易な閾値の形式合格を、人間が定めた独立の建築要求への適合と混同しない。建築の独創性、美観、図書館の実際の機能、Minecraft上の歩行や施工は未認定。原本は無改変で保持し、モデルの自動再実行や修復も実施しない。

## 安全とCI
R61テストには正常な断面、B143形式合格にもかかわらず吹き抜けが後続ADDで塞がるケース、原本/幾何SHA不一致と出力上書きの拒否を用意。専用CIを新設せず既存R60ワークフローへ追加し、R58/R59/R60と一緒にWindows/Ubuntu Node24で回帰する。

状態はNOT_PREPARED、施工ゲート9件BLOCKED、constructionApproved=false、executionAllowed=false、BuildPlan.operations=[]、world contacts/reads/writes=0。main/Freeze/旧承認ロックは変更しない。

# E2ローカルQwen実モデル1件の設計実証（2026-11-01 JST）

## 目的
E1研究施設のSOURCE成功原本とスクリーンショットから学んだ美術問題（平坦な屋根、単調な壁、弱い入口、箱形の限界）を踏まえ、E2新形式でローカル `qwen3:14b` に一度だけ小規模研究施設を独立著作させる。旧R190の3用途を再実行しない。

コマンド: `.\RUN_R125_FREE_BUILD.cmd study-e2`。内部で `node scripts/r190-e2-qwen-study.mjs` を呼ぶ。モデル実リクエストは最大1回、出力トークン上限5200、タイムアウト上限6分。今後必要なら設定と上限のある変数から調整する。モデルが応答した原文は完全なJSONに成り立たなくても可能な限りそのまま保存し、成功・失敗の判定と分離する。

## 構造
新形式 `minecraftaibuilder-e2-authored-architecture-v1` のSOURCE設計をモデル自ら選ぶ。ホストはB143ソリッドやボイド、床、ドア、窓、屋根、装飾を推測挿入しない。モデルが記した `sourceDesign` と `programSpaces`、`entrance`、`glazedOpenings` を物理SOURCEで検査する。

原文SHA、要求仕様、B143ソース、完成ボクセル、機能領域への2×2通行、外気に面した本物のガラス、構造上部の屋根証拠、結果とプレビューを別々に保存する。ファイル格納先は `E2-qwen-*` フォルダ、結果は `E2_QWEN_REPORT.json`。Windowsで結果フォルダが自動的に開く。

結果は `SOURCE_READY_ART_HOLD` または `SOURCE_HOLD`。擬似モデルテストは `TEST_DOUBLE_ONLY` として実呼出し数ゼロを明記。実モデル原文が保存されなければ無理に成功扱いしない。

## 不変
E1成功原本・ブランチmainは変更禁止。自動修復／自動再試行なし。Minecraft接触ゼロ、MakeCode出力ゼロ。技術SOURCEの成功は、美術合格、実施工、実歩行検証を意味しない。

## 限界
一段階の自由JSON設計はまだQwen3:14bの実能力がわからない。構造的なエラーが出れば原文と失敗コードを基に、建築表現またはモデル著作インターフェース自体を改良する。失敗のたびに建物固定テンプレートを導入しない。

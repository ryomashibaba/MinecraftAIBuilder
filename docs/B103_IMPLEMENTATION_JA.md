# B103 — 再生成2セル廊下・複数コア候補・全階3D監査

## 境界
Minecraft Education優先。B100/B101/B102/旧凍結原本はすべて読取専用。旧296未承認室・18保留室の状態は変更せず、Minecraft世界に接続せず、施工命令も生成しない。

## 新たな機能
1. B102で配置された各部屋の入口を読み込み、B100の固定galleryセル集合をルーティング入力に使わず、2×2アンカーを用いて部屋・コア間の幅2セル回廊を**再生成**する。
2. 既存3×3コアに加えて、各階に同じ位置を確保でき、居室に干渉せず、二階以上にも通じる追加コアを最大28案探索する。二コアで全室と接続できない場合、単一コアの結果を保持して未解決とする。
3. 地上階の外周と実際につながる空洞をフラッドフィルで判別し、距離が離れた最大2か所の概念出口候補を構築する。中庭の閉鎖空間は出口候補にしない。
4. 五セル/階の**建物全体グローバルxyz**上で床・壁・3セル空気・天井・概念入口・3×3コアの6踏み面/階間の螺旋階段モデルを監査。踏み面上2セルの衝突と室口の高さ2セル通過を検出。
5. Educationブロック名の**読み取り専用・未認証**プレビューを用意。実BlockStateの検証、ドア・階段実ブロックへの変換、コマンド発行は未実施。
6. 5用途×3案のレポートを自動生成し、30の回帰・不正入力テストを追加。

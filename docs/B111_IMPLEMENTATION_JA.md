# B111 — 室内設備の占有セルと通行可能性の検査

B110で得られた279室のドア候補・558家具アンカーを、B104の間取りと組み合わせて検証するオフライン工程。

## 実装内容

- b111-interior-access.mjs：各部屋の入口から通れる床セルを幅1セルの4方向グラフで探索。ベッドを隣接2セルで表す案について組み合わせを調査し、他の家具・入口との重複を回避する。全床セルの到達可能性、各家具への隣接アクセス、空き2x2セルの有無を測定する。
- compile-b111.mjs：5用途・15案・279室の結果を、部屋別の詳細JSON、全体レポート、実行可能な改善対象一覧、5種類のASCII室内マップとして書き出す。
- 30件の追加回帰テスト（合計576件）と、B111独立安全ゲートをGitHub Actionsで実行する。
- 既存の家具アンカーは位置を変えない。2セルベッドの副セルは仮説配置であり、Minecraftの実ベッド設置命令ではない。

## 検査できたことと検査していないこと

roomsWithConnectedSingleCellWalkways は、概念セル上で入口から全ての非占有床へ到達でき、家具の隣接位置へも到達できる部屋の数。2x2の空き床が存在しても幅2の廊下の連続性や車いす通行を保証しない。ベッド向き・ブロック高さ・ゲーム内の実衝突・プレイヤー移動や緊急避難安全性は未認証。

条件を満たさなかった部屋は ROOM_NEEDS_REDESIGN として全件記録し、数値を隠さない。

## 安全条件

B100～B110と凍結原本は変更しない。296未承認候補と18保留室は維持。NOT_PREPARED、施工許可ゲート9つBLOCKED、worldContacts=0、worldCoordinates=null、constructionApproved=false、BuildPlan.operations=[]、commandCount=0。実Minecraft Education接続・施工は行わない。

## 次工程とWorkへの切替予告方針

B112は引き続き通常チャット＋GitHubで、全体の統合監査とローカルWork用MinecraftAIBuilderプロジェクトへの安全な引き継ぎ情報を作る。**B112を完了した時点で、次のB113はローカルWorkを使うことを明示**する。その次のチャットはローカルWorkプロジェクトへ送る実行プロンプトの作成に専念する。Workの環境・アクセス権限の検査を最初に行い、許可前のMinecraftワールド接続や施工を禁止する。

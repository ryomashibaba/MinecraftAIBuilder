# B198Z-R101 — 床の誤認と未検査経路の検証抜けを修正

2026-10-23 JST。旧Qwen原本・R98源メッシュ・Minecraftワールドは改変しない。PR #128 Draft継続。

R99の床検出Rayは元々足元+0.024から下に伸びており、実床ではない低い天井を床として数える可能性があった。R101では床検出を**足元+0.002から足元-0.035**の範囲へ狭める。頭上レイは別に残す。正規化座標の研究用であり現実の身長/荷重を証明しない。

R99は源経路に「完全垂直」区間があるとその区間を飛ばしていた。今後は以下を区間別に記録し、いずれか存在する場合は `HOLD_SOURCE_SEGMENTS_NOT_FULLY_SCREENED` とする。

- 水平移動がなく上下移動する区間
- 元の研究プロキシで未証明な急勾配（平面勾配 >0.28）
- サンプル最大24分割によって宣言した0.07のサンプル間隔を超えてしまった区間

既存の床・頭上・横断のRay観測件数は維持し、未検査理由、未検査区間数を追加した。R100の実床拡張採用条件にも「**源区間全体が局所検査対象に入っている**」を要求する。条件を満たさない場合は既存HOLDとして残し、旧メッシュは保持する。

追加スモークは完全に人工的な最小三角形を使い、(1)低い天井を床と誤認しない、(2)垂直/急勾配/疎サンプルをHOLDにする、(3)実床を広げると足元未検出が減ること、を照合する。実R98・R100全館での改善件数は既存GitHub Actions待ちのため未認証。

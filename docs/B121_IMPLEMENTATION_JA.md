# B121 — 階段＋周辺廊下の同時設計（非施工）

B120で残った8出口（7本の階段）に対し、元の床・部屋・コア・**元からある廊下**を絶対に変更しないまま、直線階段および180度折返し階段と、B113/B114の仮廊下を組み合わせた局所設計案を独立監査する。

## 変更する設計範囲を厳密に区別
- **完全保護**：元フロアマスク・原典`floor.gallery`・部屋・別コア・ほかの階段の占有セル・B105構造物。
- **移設候補（未施工）**：B113の`repair.addedCells`およびB114の`addedGalleryCells`。階段の占有セルと重なる箇所のみ、仮の再配置数として記録。
- **まだ再接続を保証しない部分**：移動対象の仮廊下が別の階段・他の部屋・建物全体の通路ネットワークを再びつなぐかどうか。このフェーズでの案は**承認された移設**にはならない。

## 探索
直線階段、折返し2+3、折返し3+2の3形状×4回転×マンハッタン距離3以内（25位置）の**1階段あたり300試行**。構造干渉・支持床・人体AABBを先に評価し、その後で上下階のどちらも**元の廊下**に幅2で接続するか探索する。原典廊下への片側接続や、仮廊下だけに接続した結果は成功として数えない。

# B121 — 階段とB114未施工ギャラリー案の一体再配置（非施工）

B120の折返し階段探索で、15棟・102階段のうち、残り8出口に対して1400配置を検討したが、保護床・既存廊下・壁・人体包絡などとの干渉で候補が0件だった。本工程では特に**元から存在する廊下**と**B114だけが提案した未施工の新設廊下**を厳密に区別する。

## 設計上の新規検討

- 元建物の`floor.gallery`とB113の先行修復を絶対保護する。
- B114の`addedGalleryCells`のうち上記に含まれない部分だけは、まだMinecraftに施工されていない**設計予約**として、階段の再配置に伴う見直しの可能性を評価する（実際の削除・変更はしない）。
- B120由来の2+3/3+2、4方向、平行移動距離3の7階段1400仮配置を再調査。
- 3D階段・踊り場・人体掃引・中間支持体、B105静的ボクセル、保護室・コア・他階段、仮床開口をすべて維持した状態で上下階双方の幅2ギャラリーが再形成できるか再検査。
- 新しい廊下はB118平面BFSだけでなく、B116独立の頭上2ブロック・他階段の支持材干渉を通す。既存B114廊下をどのセルで退役候補にする必要があるか明示する。
- 全8出口を元設計への変更なしに調査し、各設計の否決理由・退役候補セル・上下両階の追加通路セルをJSON/CSV/日本語レポートに保存する。CIでは独立7テストと統合5テストを実施。

## 審査上の限界

これは設計変更の`counterfactual`（仮に設計予約を変更した場合）の検討。B114の設計案は自動撤回していない。施工時の本物の床支持、BlockState、実機歩行、ネットワーク連結、消防・安全基準を認証しない。元の9出口のHOLDはすべて維持する。

`readiness=NOT_PREPARED`、施工9ゲート`BLOCKED`、`BuildPlan.operations=[]`、`worldContacts=0`は不変。Minecraft接続・施工、元ブランチやmainの変更・PRマージ・課金変更なし。

# B121 — 階段と未施工ギャラリー案の同時再設計（非施工）

## 判定の出発点
B120の15棟66階102階段に対する7階段・8出口の1,400通りの折返し階段検証は完走したが、成立した候補は0件だった。最大の障害群には、既存または計画上の廊下との重なり、B105の壁・家具・人体包絡、床範囲・別階段の衝突があった。

B121は従来の「廊下が1セルでも階段と重なると絶対拒否」という単一扱いを修正する。ただし保護範囲を曖昧に拡張しない。

- **移動不可**：元の床・部屋・コア・他階段・B105ボクセル、元設計の廊下、B113修復案の廊下。
- **再設計の検討だけ可能**：**まだ施工されていない**B114 `addedGalleryCells` のうち、上記保護対象に重複していないセル。
- 同一5×4折返し階段について、従来の「B114追加案を含む」判定と、「元廊下＋B113の保護基準だけ」を使う仮想判定を並行実施する。
- 両方の階で元廊下ネットワークへの幅2経路を独立に探索できた場合に限り、`SIMULTANEOUS_UNBUILT_STAIR_GALLERY_REPLAN_IDEA` として記録する。
- この条件を満たしても、移動前のB114ギャラリーが持っていた枝分かれ経路やほかの階段へのアクセスは再証明していない。B114全体の連結再検証が別途必要。
- 成立しなかった場合は、B105衝突・床外・元の廊下破壊・部屋など、**緩和できない障害**を計数する。無理な移設や世界座標は生成しない。

# B198Z-R66 — 屋根下空間と開放空間の実ボクセル判別補助

対象：MinecraftAIBuilder Draft PR #128。R65以降の既存開発の続き。2026-10-22 JST。

## なぜ
R64/R65はモデル自身のspatialPlanとは無関係に床上の立てる候補と連結成分を数えられるが、完全に屋根のない床一枚でも大きな公共図書館に必要な実用空間を確保したように見える可能性がある。R66はその見落としの一部を、建築形態への一律の制限なしで補助的に検査する。

## 実装
- `scripts/b198zr66-overhead-space-audit.mjs` が、元原本の生文字列SHAと厳密なB143最終概念ボクセルgeometry SHAを確認する。AIの自己申告spatialPlanは使用しない。
- 足元に支持床、足位置と頭上1セルが空気である全立ち位置を抽出し、そのXZ列の真上にどこか一つでも固体ボクセルがあるかを走査する。床上全候補、頭上に固体がある候補、設計上端まで開いた候補、覆われた/開いた2x2の床パッド、足元から最初の頭上固体までの距離を計測する。
- 構造物の真下にいるという「覆いの代理指標」は、室内・屋根性能・出入口・避難安全性・実際の読書空間を意味しない。橋の下、木造ひさし、上層の床も『頭上に固体あり』に含む。
- 明確な屋根なしの床、ほぼすべて開放された床、覆われた2x2床がない場合は独立した人間レビュー用の注意情報を付ける。テラス・中庭・露天劇場・開いたアトリウムを禁止せず、数値だけで自動FAILにしない。
- R60の審査画面から `R66_OVERHEAD_SPACE_REVIEW.html` と原本SHAに紐づくJSONへ進める。B143 HOLDではR66の最終ボクセルを捏造しない。
- R62の次回設計候補にはR66の注意点を検証済みで追加する。R62側でR66結果を原本から独立に再算出し、数字・懸念リストが改ざん・古い場合はHOLDにする。

## テスト
完全開放100マス床、屋根下100＋屋根上100マスの床、細い庇だけの空間、spatialPlanを変造しても集計不変、全密閉固体の立てる場所0、B143やSHAの矛盾、レポート上書き拒否、R60/R62結合。新しいCIワークフローは増やさず既存R60 Windows/Ubuntu Node24で検証する。

# B125 — 上部着地点の半段単位再構成と8セル床開口保護監査

B124 PR #28をbaseとする新規・非施工系列。B122/B123/B124で継承したOFFICE_V1階段#6の候補を対象とし、15棟66階102階段の原台帳とハッシュをすべて参照する。原典、main、他Draft PRは一切変更しない。

## B124から進めた点

1. B113の0.5ブロック刻みのstraightFlightとB120の折返しモデルのサンプルを独立再計算し、B114の符号付き格子回転を用いる。
2. 再計算した各身体断面AABBが元モデルの保守的な身体スイープと一致することを検証。変更時は明示エラーで停止。
3. 上階近傍の身体断面と保護2セル着地点の床・B105ソースボクセル・他階段部材との交差を位置付きで記録。
4. B124の上階床開口を別実装で再構成し、セル・床Y・着地点交差セルの完全一致を確認。元廊下・B113修復廊下・保護室・上階着地点の削除を禁止。
5. 8セル床開口の周辺に残る床セル数を個別に記録する。荷重や床支持強度を認証するものではない。
6. 8つの合成反例テスト、5つの全15棟/安全テスト、独立Actions、JSON/CSV/日本語Markdownレポートを保存。

## 厳格な制約

- 細密な身体サンプルによる静的交差は、実Minecraft Educationの当たり判定を再現しない。
- 床の支持強度、BlockState、階段向き、ドア開閉、歩行入力、踏面の実衝突は未認証。
- 干渉がなければ限定代理形状で非検出とだけ記録する。
- 施工用ブロック命令やワールド座標を出力しない。
- 元の9出口HOLD、NOT_PREPARED、9 BLOCKED、BuildPlan.operations=[]、worldContacts=0を厳守する。
- B125の合格でも施工HOLDを解除しない。

## 次工程

細密断面・床開口で新しい危険点が出れば、座標つきの要因から非施工の設計候補を絞る。問題が出なくても教育版でのBlockState・衝突・荷重を別途検証するまで施工準備完了とは認めない。

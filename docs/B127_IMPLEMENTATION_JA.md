# B127 — 半段階段の設計上の向きとEducation実機校正ゲート

B126 PR #30をbaseにした非施工の追加工程。B113の5段×2幅の仮想階段について、B119/B114の回転された元の踏面形状と仮想上下半段モデルの設計幾何が一致するかを独立にテストする。

## 本工程で実装したもの

1. 階段5段・幅2レーン・踏面前後2区画・下半/上半2区画で合計40個の設計上の幾何サンプルを判定。
2. 最上部の床開口はB125のセルと照合し、階段ブロック候補はB126の10セルとすべて座標一致必須。
3. B114の4方向回転を独立反例テストで検証し、計測資料の差し替え・セル欠落・安全状態の改善偽装は即時エラーにする。
4. generic Bedrockのweirdo_direction=0/1/2/3と実空間4方位の対応は実機不明であるため、全単射24通りを未校正候補として保存する。ソース幾何の向きからEducationのBlockState値を断定しない。
5. 15棟66階102階段の元台帳、B125・B126の実データとハッシュに紐づけて、日本語MD/JSON/CSVをCIで出力。

## 何を認証しないか

- 実際のMinecraft Educationの階段BlockState受付、配置時の向き、角階段への自動変形、階段の当たり判定。
- プレイヤーの昇段・ドア開閉・床支持荷重・ワールドへの実施工可否。
- 半段のサンプル比較は元の設計モデルへの整合だけであり、実機における踏面形状の検証ではない。

## 安全

実機接続なし、worldContacts=0、worldCoordinates=null、operations=[]。原9出口HOLD、9 BLOCKED、NOT_PREPARED、BuildPlan.operations=[]を維持。元mainや先行Draft PRには書き込まない。

## 次に必要な実機情報

WindowsのMinecraft Educationにおいて独立した小型の検証対象を用い、配置操作・readback・方向と上昇の対応・段差実移動を測定しなければならない。ただし、本工程はその操作を行わず、承認も与えない。

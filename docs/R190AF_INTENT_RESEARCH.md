# R190-AF: Architectural intent as a separate source-only research boundary

The *root* is structurally different from child rooms: it has no parentId or side keys.
Other rooms author their parent and cardinal side; the host normalizes the root
into the frozen R190 compiler only as a deterministic representation mapping.
This is not new Qwen inference or a change to existing AB/AD/AE schema hashes.

Windows are **daylight intents** (room, face, requested size) not coordinates.
The host computes a bounded **unapproved proposal** without adding glass or
declaring that wall exterior. If no valid coordinate range exists, the proposal
stays HOLD, never shrinks a room or window and never invents an approval.
Even a provisional source preview is not a completed architecture: neither
usable climate performance nor Minecraft walking nor aesthetic quality is
certified. There is no request to a provider and no Minecraft interface.

The AF pilot is an independent, offline candidate study, **not** yet attached
to the Ollama run workflow. An additional, model-approved selection contract
and true exterior wall/door checks would be required before creating glazed
3D evidence. Do not run a real Qwen trial on this stage.

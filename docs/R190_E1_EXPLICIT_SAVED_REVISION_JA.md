# E1保存済み原文の明示的改訂モード

初回二段階実験ではQwen原文3件はすべて保存済み。住宅は物置高さ6、花屋はレイアウト3戦略とも不可、研究施設は窓幾何候補0。従来のプロンプト調整で無条件に3件再生成する方法は不要。

`node scripts/r190-e1-revise-saved.mjs` を**ユーザーが明示的に実行した時のみ**、保存済みの最新 `E1-two-stage-*/STAGE_A_ORIGINAL.txt` のSHAを確認し、元の原文と違反説明をQwenへ提示して1回だけ新しい完成プランを作成させる。ホストは原本を修正しない。必要な屋根、配置、容積、窓が成立するように著作者Qwen自身が自由に再設計する。真正SOURCE候補がある場合だけ第2段階のQwenが明示選択し、旧B143ソース・3Dビューア・MakeCode安全契約で検証する。

各用途のモデルリクエストは最大2回（Stage A改訂1＋窓選択1）で、HOLDは停止。再試行なし。旧原文の参照パス、SHA、エラー、改訂原文、窓選択原文、最終合成、レポートをすべて**別のE1-revise-saved-フォルダ**へ保存する。旧実験ディレクトリを一切変更しない。

研究用・美術未審査／ワールド書込0。SYNTHETICテストはREALモデルと完全区別。失敗原因の詳細は `E1_REVISION_REPORT.json` と独立証拠に記録。ARTを合格扱いしない。main・凍結原本・旧E1研究経路は変更しない。

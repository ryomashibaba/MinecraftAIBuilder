# B198Z-R102 — R88実端点へつながる連絡床のテーパ形状を研究

2026-10-23 JST、同一ブランチの Draft PR #128 継続。原本・Minecraft世界は不変更。

## 目的
R100の連絡床は全長にわたって矩形の張り出しを付けており、元R88の細いデッキへ急に接続している。R102は単なる証拠追加ではなく、この**接続部の実3D床面を変更する比較モデル**。旧R100が実モデル上で床支持の限定改善を観測したことは既存CIで確認できたが、具体的な経路数・人の移動は認証されていない。

## 形状と採否
- 各accepted R100連絡線で原R88半幅0.016を両端に保持、最初と最後の18%で半幅0.030に広げる。幅変化の位置が実三角形8面へ反映される。
- **ゼロ面積の見かけの三角形は作らない。** 両端各1三角形と中間2三角形、左右計8面を設計。候補が吹抜け保護帯（|x|>0.40）を侵すと不採用。
- 旧R98源4,692面exact prefix、旧R100と比較。R101厳格Rayで従来の源床未検出が減り、頭上・横断の新たな交差がなく、改善レイが元R100案の最低60%以上かつ1件以上、未検査区間0の場合のみテーパ採用。
- テーパが不成立なら、その連絡通路だけ元R100矩形床帯を残す。R100で未採用の通路は未採用のまま。低品質モデルを無条件に採択しない。
- JSON（7接続の改善レイ数、採否理由、源SHA）、R98/R100/R102同一カメラ6視点HTMLと実OBJを既存R60レビューに追加可能とする。
- 人の体積・耐荷・支持・施工・美術認証は行わない。新たな汎用AI生成成果ではない。
- 通常Push/PRのCIは軽量な人工形状テストだけ。7接続の全源実メッシュテストは既存の手動完全回帰に維持。テスト実行結果を確認する前に実採用件数を断定しない。

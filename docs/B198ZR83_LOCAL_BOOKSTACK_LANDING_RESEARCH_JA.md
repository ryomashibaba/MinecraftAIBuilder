# MinecraftAIBuilder B198Z-R83 — 書架段丘の実三角形を利用した局所踊り場研究

2026-10-22 JST。既存Draft PR #128 / `feature/b198zr1-protected-architectural-revision`を維持し、R82 Windows/Ubuntu CI成功を確認して開始。

## 背景と設計上の優先
R79→R82で図書館の曲面翼・巨大アトリウム・概念昇降デッキを実三角形へ展開し、入口/上部ラウンジの中心線交差と書架段丘への距離を測定できるようになった。しかし「近い段丘がある」ことは実際の閲覧床へ踏み移れることを証明しない。R83では大空洞を最短橋で塞いだり、全ての書架階を自動で結ぶことを避ける。まず左右1か所ずつ、実際の書架段丘三角形に内包される局所踊り場の研究案を比較する。

## 幾何学的な処理
- 凍結原本SHAとR62→R76→R77→R78→R79→R80→R81→R82の保存された証拠を毎回原本から再計算・照合。B143 HOLDはHOLDのまま。
- R82が測定した左右の昇降経路の節点と既存書架段丘の距離の中から、各翼1節点を決定的な計算順で抽出。美術の正式採択順位や実際の工事距離の最短を主張しない。
- その節点から再びR81の`left_reading_terrace`または`right_reading_terrace`の実三角形を独立に検索。三角形内の重心方向に内挿した3頂点を設け、書架段丘の上に小さな研究用の踊り場（三角形）を生成する。架空の支持床や外殻を新たに塗りつぶさない。
- 入口側のデッキ節点から着地点へ、短い直線状の連絡面が検討可能かを距離・傾斜・既存外殻中心線との交差・アトリウム進入で判定。研究条件を満たさない場合は**面の追加を拒否し、明確な保留理由を保存**する。
- 判断閾値（長さ0.035〜0.28、傾斜0.28以内等）は正規化形態研究の局所候補フィルターに過ぎず、人間の歩行、Minecraftキャラクター、法規、安全基準ではない。中心線の交差が0でも幅を持つ全デッキの衝突・頭上余裕・踊り場の支持・荷重は不明。

## 出力
`scripts/b198zr83-wing-terrace-landing-prototypes.mjs`と対応の新規テストを追加。`R83_WING_LANDINGS_AND_ROUTE_GAPS.json`には各翼で選んだR82の節点・元の3Dずれ・書架段丘三角形インデックス・局所踊り場座標・連絡面の採否と理由を記録。`R83_READING_WING_LANDING_STUDY.obj`はR81の元三角形メッシュにR83の研究用踊り場（条件を満たす場合のみ短い連絡面）を重ねたもの。`R83_BOOKSTACK_ACCESS_GEOMETRY_REVIEW.html`に正面・斜視・側面・俯瞰の4視点と比較表を掲載。既存R60一回ZIPレビューの目次から開ける。R79/R80/R81/R82の結果・原本は一切上書きしない。

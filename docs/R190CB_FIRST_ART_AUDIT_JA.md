**ART REJECT／採用0**。作者の当初の意図である「街路から裂けた主殻・空中の公共空洞・独創的な天空レストラン」を、真正ボクセルによる外観が満たしていない。SOURCE技術（作者明示動線、最終実セル、別査読）は別の評価とする。

## 検査した実物
- GitHub [R190-CB初回CI #41067774403](https://github.com/ryomashibaba/MinecraftAIBuilder/actions/runs/41067774403) では**負例を含むNodeソーステスト5/5成功**、その後3DビューのB143安全契約不足で**失敗**した。失敗を隠さない。B143 coreの`worldCoordinates:null`必須契約があるのに、CBビューにこのフィールドが欠けており、既存安全チェッカーが正しく表示を拒否。`scripts/r190cb-source-study.mjs`に必須フィールドを追加し、`scripts/r190cb-circulation.test.mjs`に受理／拒否回帰を追加。**再実行は別CI**で結果を確認する。
- 初回失敗ジョブからも`ORIGINAL.json`と`ALL_VOXELS.json`を回収できた。**最終46,829真ボクセル**、原本と物体のSHAがあり、作者明示267動線アンカー。これらをSOURCE以外から創作せず、別工程のNumpy/Pillowで5投影＋3遠近の実物モンタージュを作成、視認した。遠近描画は実表面点の近似なので、画素色や面密度を構造証拠とは解釈しない。
- 正面／背面：太い連続外殻と幅一様な水平色帯が主張。上部の片側への張出しがあるが、シルエットの抜本的な新規性は弱い。
- 側面：奥行きに厚い箱型の壁が終始優位で、採光孔は小さく孤立した欠けとして映る。特に東西からは新しさの印象が失われる。
- 斜め／地上：先細りの上部と基壇は見えるものの、上層に向けて主殻が力強く変形する姿ではない。大空洞による都市スケールの立体的ドラマも見えない。
- 空洞内カメラ：点スプライトの密な状態と視点の近さから識別性が悪く、空間の美しさを判断する根拠としては不十分。ここを勝手に美術PASSとみなさない。

## 技術上の前進と限界
- **良い技術**：R190-CAで設計していなかった垂直方向のルートを、2×2の実床・頭上3セルの作者明示踏面・折返し踊り場として原本に含めた。作者意図をホストが勝手に補完しない方針を維持している。
- **限界**：高さ84の経路は実Minecraftの階段スラブや当たり判定の操作試験ではなく、「水平2セル離れた踏面間を高さ1上昇可とみなす」という研究用の別の代理モデルである。CAの水平1セル・1段差BFSと無条件に同一比較してはならない。
- 上階への連続移動が設計できたからといって、道路からの入口・二層大広間の内部歩行・全オフィスへの分岐・レストラン客席・耐荷重・施工が成立するわけではない。
- そのため**SOURCE/VIEW QA、ART、FUNCTION、STRUCTURE、REAL_MC_MOVEMENT**を分離する。修正版CIの結果が出るまで技術全体PASSを宣言しない。

# B198Z-R68 — 自己申告によらない水平空気の連続性と閉鎖空間の検査

基準日 2026-10-22 JST。MinecraftAIBuilder、Draft PR #128。現行Freeze・旧原本・main不変更。

## R67の制約を解消する
R67は『前後左右に固体が近い』ことを確認するが、四隅の柱だけでも壁に囲われた部屋に似た数値が出る。また、モデル宣言された入場位置や部屋名は実体を保証しない。R68は最終B143ボクセルだけを使い、床の有無に左右されない同一階高・頭上2セル分の空気を水平方向に連結して各空気成分の実態を調べる。

## 解析方式
- `scripts/b198zr68-horizontal-air-continuity.mjs`：保存原本SHAと最終B143 geometry SHAを厳密再計算・照合。モデルのspatialPlan・部屋名・自分で設定した最低値を使わない。
- 各y階で空気の2セル高条件を満たす全位置を4近傍でflood-fill。**床に支えられた位置だけでグループ化しない**ため、床が終わった場所の外側の空気も通路として数え、開放デッキを偽の閉鎖室にしない。
- 連結した空気成分のうち、支持床＋頭上2セルの空気を備え、さらに頭上に固体がある位置数を計測。局所設計グリッド端へ同じ階高でつながるか、閉じた空気領域か、壁面に隣接する空気セル数、2x2連続床の領域数、主要上位16成分の詳細をJSON/HTMLに出す。
- **密閉された空気は使える部屋の証拠ではない**。入口や垂直動線がない可能性がある。反対に扉がある室内はグリッド端まで空気がつながり『開放』と判定され得る。設計グリッド端も実際の建物の外側とは限らない。上下方向の空気の連続は別の調査とする。
- 一律の建築形状、建物最小規模、閉鎖率閾値を要求しない。大空洞・柱列・露天の中庭・実際に入口のあるホールを誤って棄却しない。用途と独創性の評価は人間が行う。

# B198Z-R118 — 連続読書座面の後退と高窓灯籠の一体改修

## なぜ庇だけでは直らなかったか
[R117実メッシュWindows・Ubuntu CI](https://github.com/ryomashibaba/MinecraftAIBuilder/actions/runs/40037989415)で実証：R107元メッシュでは頭上7件とも源R93庇三角形4474。R113とR115の最大改修で同7件は**読書用座面4476**に移る。改修後の座面への実Ray交点は高さ0.4737〜0.4740、床に基づく移動線は0.4608〜0.4612（全て正規化値）。旧設計は「庇を直したら座面が残る」という二層の本物の干渉だった。元7件の実交差は消していない。

## R118で制作した実3D建築の候補
[コード](../scripts/b198zr118-reading-seat-clearance.mjs)／[テスト](../scripts/b198zr118-reading-seat-clearance.test.mjs)。
- R115の実源2枚の庇と接合した書架壁2枚の上昇量+0.16を起点にする。さらに、R93真正座面4476を含む**全共辺連続座面帯**を実源から探索。手前縁のみを35%・55%・70%・82%書架方向へ後退し、座面の後縁/書架・床・玄関・他の部材は変更しない。
- ベンチの実三角形面積がゼロにならないこと、面数・共辺連続性が保存されること、残存座面の正規化奥行きが少なくとも0.0085、旧幅の17%以上であることを要求。未変更の建物面に座面前縁が共有されている場合は「接合切れ」として不採用。これは椅子の人体寸法や美術的品質の証明ではない。
- 同じR98/R107原本SHAを検証後、現行のR110源床9×幅3=27サンプル＋全区間、R99の床/頭上/側面の実源Ray、既存R107の5本通路の非悪化で各候補を判定する。**頭上7未満かつ他条件が非悪化**なら初めて研究用形状候補とする。採用不能なら元R107の全建築メッシュを返す。
- R118の候補は元R93座面と庇を物理的に編集した三角形メッシュであり、移動用のプローブの座標だけを変更するものではない。レビューは既存R60出力経路の`R118_JOINED_READING_SEAT_SOURCE_EVIDENCE.json`と`R118_JOINED_READING_SEAT_ARCHITECTURE.obj`。採用時に限りR114の**元全館/候補全館/実変更面の3ペイン×6視点**に掲載する。

# Step 8B/B16 — 非施工の部屋・廊下・階段接続グラフ

## 実装した工程（B16.1〜B16.6）

1. **来歴固定**: B15パッケージを基準とし、B14概念境界5,704辺・B12ドア314接続・B15仮想壁試算をそのまま保持。B14/B12固定レポートの再構築とハッシュ照合。
2. **平面接続監査**: 30階それぞれについて、廊下セルの4方向隣接成分と、部屋ドア側の廊下接続を計算。廊下の次数1セルは*行き止まり候補*としてのみ記録し、避難・火災安全とは扱わない。
3. **未適用の補正比較**: オフィス02の廊下端18セルを仮に除いた場合の成分数・ドア接続・階段への概念経路を、原案と並べて比較。元案は変更なし。敷地外や予測内セルを勝手に除く案は拒否。
4. **上下階の概念位置整合**: 5棟×上下5階間=25箇所の階段予約XZ位置の一致だけを確認。実階段、踊り場、頭上空間、ドアの開閉・通路幅、エレベーター移動は未確認。
5. **安全・改ざん拒否**: 世界座標・実材料・実行操作が含まれる入力、変更ドア、偽の施工許可、ハッシュだけ付け替えたレポートを拒否。
6. **レビュー・QA・復元**: 建物/階/原案・廊下端補正の切替ができるHTML、未承認レビューJSON、B16新規25テスト、前工程テストを分割回帰、ブラウザ実操作、ZIP整合性確認。

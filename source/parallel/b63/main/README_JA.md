# B63 仮想壁厚・設備離隔の非施工照合

## 目的
B62の 3/4/5 セル廊下候補を、B18が過去に生成した **厚さ0.125セルの仮想壁・ドア開口（実ブロックではない）** と2D/3D軸平行直方体で照合する。

- 歩行者の仮想断面は0.5 / 0.75 / 1.0 / 1.25セル、仮想高さ2セルで、候補セル中心に固定。
- B18の壁直方体は y=0〜2 に実体がある場合のみ交差判定。ドアの上部まぐさ等は配置された位置に従って判定。
- EV・階段の予約セルと仮想断面との面積重なりも、幅ごとに再計算。
- 周囲の模式壁ID、室IDと最短距離を追跡。ただし室の面領域マップはこの凍結入力に存在しないため**室の占有判定はUNKNOWN**。

## 結論の限界
5セルの直線候補は仮定幅1.0セル以下ではB18模式壁とEV/階段予約が重複しない。1.25セル幅ではEV予約と4セルが重複。これらは**B18仮想モデルに限定した計算結果**であり、Minecraftの通路幅・壁厚・安全な昇降設備のクリアランスの証明ではない。

ルーム所有候補はF1-R012とF1-R013の模式壁から抽出されるが、廊下候補がその部屋に属するかは未確定。実ブロック・材質・世界座標・ドア状態・実際の移動判定は不明。全候補HOLD。

```
cd source

node parallel/b63/main/run-b63.mjs
```

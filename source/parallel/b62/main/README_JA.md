# MinecraftAIBuilder B62 — 設備予約と廊下候補の衝突検証（非施工）

## 概要

B61で「最小3セル」とされた D012 向け廊下候補は、B14・B17で固定されている**3×3の名目エレベーター予約のうち3セルを侵食**していた。B62は過去の成果物を改変せず、設備予約を明示的に排除した別の候補を計算する。

- B61案: 3セル `(21,18) (22,18) (23,18)` → エレベーター予約と3セル重複。設計として採用不可。
- エレベーターのみ回避: 4セル `(14,18) (13,18) (12,18) (11,18)` → 階段予約と3セル重複。設計として採用不可。
- **エレベーターと階段を両方回避**: 5セル `(19,20) (20,20) (21,20) (22,20) (23,20)` → 名目予約との平面重複0、概念グラフ上78/78。**未承認候補**。

B14とB17の設備予約・名目壁境界について別個の証拠を照合する。5セル経路について名目境界の線分横断は0件だが、近傍の境界IDを記録する。室内占有、実際の壁厚、扉状態、1セル通路の通過可否、シャフトとのクリアランス、頭上空間、本番エミッターとの整合性は未検証。

## 再現

```sh
cd source
node verify-b62-package.mjs
node --test parallel/b62/main/compile-b62.test.mjs
node parallel/b62/main/run-b62.mjs
```

`parallel/b62/main/B62_OFFLINE_CONFLICT_REVIEW.html` は単体HTML。表示だけでMinecraftにもネットワークにもアクセスしない。ブラウザでは生成HTML内容を直接読ませて3案の切替とJavaScriptエラー0件を確認した（検証環境では file:// 直接ナビゲーションが制限される）。

## 安全境界

`NOT_PREPARED`、9ゲートすべて `BLOCKED`、`BuildPlan.operations=[]`。実建築・スキャン・エミッター呼出し・ワールド接続なし。B61以前のソースに編集なし。

**B63への課題**: 本番ソースの読み取り専用受入れ、実物のシャフト／壁・部屋占有と扉・通路幅・階段支持の確認。B61の3セルを「修正済み」として書き換えず、不適合の証拠として固定する。

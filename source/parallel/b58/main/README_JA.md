# MinecraftAIBuilder B58: Vertical Core & B42–B57 Floor Mask Reconciliation

## 目的
本番コード未取得の制約下で、現行5棟30階の床面形状から、全6階に共通して残る縦コア候補領域を検出し、旧B42階段レビュー用マスクとB57外形基準を独立して照合する。

## 実装内容
- 5棟の6階共通床面をラスタ再計算（領域交差）
- 2×2・3×3・4×4ローカルセルの完全共通配置数、代表候補を算出
- 15入口案から2×2共通領域への床面4近傍BFS距離を算出（壁・ドア・段差は考慮しない）
- B42アパート5階間の「候補**上階**床マスク」とB57上階基準を全セル比較
- 階段前面/着地点のB57内座標被覆、B42候補コネクタのB57平面被覆を解析
- 破損・改ざん・承認フラグの拒否、検証レポートのハッシュと再計算

## 重要な意味的制限
- B42のL1→L2マスクは上階の代理であり、**L1の床面保証ではない**。
- 旧B42とB57の差を「自動修復」しない。今後実ソースが揃ったとき、どちらのスナップショットかを確認してから選ぶ。
- 床面2D距離は障害物を無視した下界値。**通行・階段・避難・部材配置ができる証明ではない**。
- 「2×2」の数値は概念セルの幾何学チェック用サイズであり、Minecraftの階段寸法や安全基準を指定しない。
- 本番 `composeFacade`, `architectural-quality.js`, `architectural-library.js` などの原本は依然未取得。B58による実コードの互換性達成ではない。

## 実行
```
cd source
node verify-b58-package.mjs
node --test parallel/b58/main/compile-b58.test.mjs
node parallel/b58/main/run-b58.mjs
```
`--export` は出力ファイルが存在しない初回だけ許容（`wx` で上書き拒否）。

## 安全性
全体がオフライン。`NOT_PREPARED`、施工前9ゲート全 `BLOCKED`、World/Minecraft API接続・スキャン・施工0。B57以前のファイル変更禁止。

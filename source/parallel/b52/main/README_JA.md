# B52 — 建物群の外壁・入口・屋上を横断する非施工案の比較

## 実装の目的
B51の5棟30階の確定済み**局所形状**を編集せず、建築全体の設計レビューを一度に行えるようにする。B51までのレポートは全件保存し、原本に基づく入口91案と屋上2D平面1,464案を比較可能な3設計方針にまとめる。**これは本番の建築配置を決める機能ではない。**

### 比較の3方針

1. `MINIMIZE_FACADE_GRAPHICS_CONFLICT`：入口付近の窓・フィンの*表示マーカー*との衝突を抑え、屋上は局所余白・中心位置を優先。
2. `CENTERLINE_COMPOSITION`：入口・屋上の局所中心軸への近さを優先し、表示衝突・屋上余白を次順位として扱う。
3. `SETBACK_WITH_OFFSET_COMPOSITION`：同じ屋上端余白を確保できる案の中で非対称の屋根シルエットを比較。入口も床被覆を優先しつつ中心外に寄せる。美観・実施工の正しさを保証するものではない。

各候補のローカル位置、判断指標、未解決フラグ、既存B48/B49/B51のハッシュを明記。相異なる候補がない場合は同一案であることを `sameLocalPositionsAs` に記録する。**自動承認・本番選定はしない。**

## B52の主な新規機能

- B51と独立した実際の屋根マスク再走査で**局所2次元屋上案**を再列挙。全探索候補の境界余白（0/1/2セル）・中心距離・直下階の平面投影の重なりを記録。これは荷重支持・防水・アクセス検証ではない。
- 入口は北壁の局所位置、4帯までの内側の床形状、窓/縦フィン**表示**の重複と中心偏差を照合。実際の扉・通路・階段・屋外接続は未保証。
- 入口・屋上それぞれの比較指標について、優劣を同時に扱うパレート非劣案を算出。指標は非施工の視覚設計と幾何学に限定。
- 外壁列の階間での**表示役割の変化**を方向別・多い列順に集計。実際の開口や壁の強度とは異なる。
- 3方針×5棟＝15レビュー案、3つの棟横断の比較表 (`portfolio`) を作成。視覚的候補と工学的承認を完全分離。

## 強制安全境界

- `NOT_PREPARED` とM4施工前ゲート9/9 `BLOCKED`。
- `executionAllowed=false`、`BuildPlan.operations=[]`、`worldCoordinates=null`、`materialIds=[]`。
- `engineCalls=0`、`minecraftCommands=0`、`scans=0`、`buildOperations=0`。
- Legacy・既存建築・凍結ファイルを書き換えない。Minecraft/HTTP/Bridge/WSに接続しない。実施工・スキャンは禁止。
- 本番 `composeFacade`、`architectural-quality.js` 等の未収録ソースを推定実装したとは扱わない。物理支持・防火・屋上アクセス・扉など未検証。

## 実行（Node.js、完全オフライン）

```bash
cd source
node verify-b52-package.mjs
node --test parallel/b52/main/compile-b52.test.mjs
node parallel/b52/main/run-b52.mjs
```

`run-b52.mjs --export` はレポートが**存在しないときだけ**新規出力。実行済みレポートを上書きしない。前工程の `verify-b51-package.mjs` はB52の新ファイルを許可しないので、B52専用検証器を使う。

## B53 推奨

本番ソースのハッシュ一致する正式な取り込みが可能なら実際のファサード規則照合へ。無ければ、今回の比較結果を用いて階ごと/棟ごとの**読みやすいレビュー可視化**、外壁リズム変更案の出所付き非施工評価を実装する。本番とのパリティやMinecraft内テスト実施は主張しない。

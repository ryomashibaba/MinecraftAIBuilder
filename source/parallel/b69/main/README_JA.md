# B69 — ローカル離散シェル生成（完全オフライン・施工不能）

## 実装の位置付け
B65の壁境界とドア開口（元IDを保持）、B66の非実体3D壁・開口箱を**変更せず直接利用**し、
ローカル整数座標上の離散スロットへ展開する。B68の本番コード受入れゲートは既存実装を呼ぶだけで、
収集機能・静的解析・仮想3Dビューアを複製しない。

- XZは概念セルを2倍化した整数格子。奇数＝セル中心、偶数＝セル境界。YはB66の仮想階高5に対応。
- 1壁境界につき、ソリッド壁ならY方向3スロット、ドア候補なら上端1スロットを生成。ドア候補の下端2スロットは**空き領域**として保持する。
- 壁・開口・室・廊下のIDを保持、連続B66箱との座標・部材種別の整合を確認。
- 階段はB65/B66の予約セルだけ保持し、実階段やヘッドクリアランスは生成/検証しない。
- レポートはブロックID・パレット・建築コマンド・実ワールド座標・API呼び出しを持たない。

## 実行
```
cd source
node verify-b69-package.mjs
node parallel/b69/main/run-b69.mjs
node --test parallel/b69/main/compile-b69.test.mjs
```
`node parallel/b69/main/run-b69.mjs --write` で凍結済みB65/B66/B68からローカルレポートを再生成する。
ソース互換性も Minecraft 内の物理品質も保証しない。`--source-zip` を受け付けず、
本番ソースの静的受入れは **B68本体のみ**使用する。

## 安全と正確性
- `NOT_PREPARED`、M4 9/9 BLOCKED、`executionAllowed=false`、`BuildPlan.operations=[]` を維持。
- 5実ソースファイル 0/5、productionParity=UNVERIFIED。B68の受入れが0/5の時だけ本固定レポートを生成。
- `summary.solidVoxelPreviewSlots` は**Minecraft実ブロック数ではない**。
- 「ドア用2スロットが空き」は仮想平面上の検査だけで、実際の歩行・扉の回転状態・開閉・衝突判定を意味しない。
- B42上階60ドア未検証、B62–64の5セル迂回は未承認。既存凍結原本は不変更。

## 本番統合ブロッカー
次に必要なのはB67の収集ツールで得られる**実ファイル5件の正しい受入れ**。
原本ソースがないまま新たな模式APIアダプターを作ることは避ける。受入れ後はB68で識別した実APIの実装根拠を確認し、
このB69レポートを既存実生成エンジンへどう取り込むかを決める。ただし元ソースの無断実行は禁止。

# B51 — 建築インターフェースの形状契約（非施工）

## 概要

B50から、新規の非施工契約レイヤーを追加。出典はB48床・屋根正規化済みの局所矩形、B49外壁辺の役割、B50表示専用ベイ・候補評価。**本番建築エンジンとの完全一致は確認できない。** `dev/architectural-quality.js` / `modules/architectural-library.js` / `dev/building-grammar.js` の該当実体は元ZIPに無い。参照プランナー呼出断片のみハッシュ固定。

### 1. 入口の床領域確認

最下階の北外壁から内部へ0～3セル分の4本の帯を対象に、候補幅の床マスク被覆を計測する。入口91候補は表示グラフィックとの重なりを示し、**扉の存在・間仕切りクリアランス・階段への経路・防災上の避難能力を示さない**。前景・敷地外へのアクセスも未検証。

### 2. 屋上の平面契約

B49由来の固定Zの91候補を全件保持し、屋根/最上階床/直下階床の被覆と、屋根縁1・2セルの局所余白を測定。加えてB51独自のローカル2D検索で屋根内の3×3または5×3足場候補を全列挙し上位5件のみ一覧化（総探索件数は記録）。この探索はB49/本番の候補を上書きせず、**屋根荷重・材料・屋上出入口・支持構造を保証しない**。

### 3. 外壁の階間グラフィック契約

5棟30階の外壁3,022単位を局所列（方向、固定座標、列内位置）に照合。元の窓表示／縦フィン／未割当の3役割を変更せず、同じ列の隣接階で役割が同じ/変化する/間が空く箇所を抽出。**実際の窓の開口・壁接続ではない**。

### 安全境界

- `NOT_PREPARED`、施工前M4ゲート9/9 `BLOCKED`、`executionAllowed:false`、`BuildPlan.operations:[]`。
- `engineCalls:0`、`minecraftCommands:0`、`constructionOperations:0`、ワールド座標なし・素材なし。
- ファイルを書き出す場合は `run-b51.mjs --export` で**存在しない場合のみ**新規作成。スキャン、実施工、HTTP、Bridge、Minecraftへの接続は禁止。
- B50以前は一切編集せず、**B51ファイルを追加するだけ**。

### 実行（Node.js / オフライン）

```bash
cd source
node verify-b51-package.mjs
node --test parallel/b51/main/compile-b51.test.mjs
node parallel/b51/main/run-b51.mjs
```

本番の`composeFacade`等のソースが検証済みの形で入手できれば、初めて本番モジュール出力との静的互換性検証へ進む。未取得の間は非施工の設計品質向上に留める。

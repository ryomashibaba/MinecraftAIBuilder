# B60 — 未施工の階段・間仕切り・ドア統合契約

`run-b60.mjs` は B59 / B57 / B42 / B31 のハッシュ付き原本と、B59の固定SHAマニフェストで保護されたB43の2ファイルから、**純粋に記号的な**6階接続グラフを再計算する。

* B42原案: 上階5層65概念ドアのうち到達5、未到達60。変更なし。
* B43未承認変更案: 6階78ドアのうち記号的グラフ接続77、未接続は1階D012。条件付きであり旧B42の結果の「修正完了」ではない。
* B43案に含まれる廊下追加: 35セル。壁・部屋割付の再検討候補: 20セル（壁候補IDは重複を除き25）。この変更は未施工・未承認。
* 6階の模式廊下: 836セル。記号的階間接続: 5本。実際のブロック状態・壁厚・開口クリアランス・階段頭上空間は未検証。
* B42代理上階398セルとB57上階400セルの差2セル×5比較は維持。自動統合しない。

## コマンド
```
cd source
node verify-b60-package.mjs
node --test parallel/b60/main/compile-b60.test.mjs
node parallel/b60/main/run-b60.mjs
```

非施工の `heldDesignActions` は施工APIではなく、設計検討候補。`BuildPlan.operations` は常に空。
B43設計モデルが77/78でも実物では1件も施工許可できない。`NOT_PREPARED`・9ゲートBLOCKEDを厳守。

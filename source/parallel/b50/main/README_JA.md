# B50 非施工・外壁モジュール設計レビュー

## 位置づけ

B49の外壁アトラスを読み取り、**施工禁止のまま**、1) 表示専用ベイへの割付、2) 入口候補と既存の窓/縦フィン表示との干渉レビュー、3) 屋上水平位置レビュー、4) 階をまたぐグラフィック連続性、5) 内部ドア未検証ヒントとの関連付けを一度に生成する。

**本番ファサードとのパリティは証明していない。** B49 ZIPには `dev/reference-engine-general-building-planner.js` の呼出箇所はあるが、そこから import される `architectural-quality.js`（`qualityComposition`と`composeFacade`定義）、`architectural-library.js` の実装本体は含まれない。したがって、本番のベイ幅、品質パラメータ、材質、ブロック状態、屋上と入口の確定位置はすべて未検証である。`run-b50.mjs` は上記の欠落を明示的に検出・記録し、ハッシュ固定したプランナー断片を**読むだけ**で、importや実行をしない。

## B50の純粋な表示モデル

- **外壁ベイ**：B49の3,022局所壁辺を窓表示・縦フィン表示・未割当の役割に基づいて重複なく、最大4単位の短いベイに切る。この「4」は**B50独自のレビュー用仮値**。`composeFacade`の本番幅ではない。B49原本の窓・フィンを改変せず、窓開口はゼロ。
- **入口レビュー**：B49の各入口候補を「表示上で窓候補に重なる数×5 + フィン候補に重なる数×3 + 中心ずれ/100」という**任意のレビュー用スコア**で比較し、先頭候補を仮の表示予約として提案。5棟の`quality.entranceBias`と実ドアは未固定。B49のマーカーを削除しない。
- **屋上レビュー**：既存の屋上水平位置候補91から矩形中心に近い順にレビュー用候補を並べる。`roofVariant`、モジュール高さ、構造支持、屋上アクセス、実素材は未検証。
- **階間グラフィックレビュー**：同じ向き・位置にある外壁辺について隣接階の表示役割変化を列挙。物理的な柱・梁の接続や壁の品質保証ではない。
- **安全性**：全出力に`NOT_PREPARED`、M4ゲート9/9 `BLOCKED`、`BuildPlan.operations=[]`、`executionAllowed=false`、材質空、ワールド座標null、実エンジン呼出0を固定。

## 実行

```bash
cd source
node verify-b50-package.mjs
node --test parallel/b50/main/compile-b50.test.mjs
node parallel/b50/main/run-b50.mjs
```

データファイル `B50_FACADE_DESIGN_REVIEW.json` は再計算済みの設計資料。`--export` は**ファイルが存在しない場合にのみ**書き出す安全機能。`B50`によるスキャン・施工・外部接続・Minecraft起動は一切不要。

## B51への推奨

次は、実 `architectural-quality.js` と `architectural-library.js` の正しい出典・ハッシュ固定が可能であれば本番側ファサード割付仕様との差分を始める。取得できなければ本番パリティを偽装せず、現行レビューの入口・階間連続性・屋上支持の**検証可能な設計契約**を深める。WindowsやMinecraftでの実作業はまだ行わない。

# MinecraftAIBuilder B53 — 建築案オフライン可視化・階間外壁リズム比較

## 目的と完成範囲

B52の建物群ポートフォリオを **形状を一切変えず**に視覚比較する。B48の床/屋根の局所矩形（5棟30階）、B51の外壁ローカル列/表示役割（3,022単位）、B52の15案を同時に見る。HTML は CSS/JS/JSON 内包のローカル参照ビューアで外部資源・ネットワークを使わない。

### 操作

ZIPの `source/parallel/b53/main/B53_VISUAL_REVIEW.html` をブラウザで開く。建物（5）・比較方針（3）・平面階（6）・外壁方位と固定位置を切り替える。外壁リズムを確認するには `孤立した表示差を抑えた試案を重ねる` を有効にする。HTMLのみ別のフォルダにコピーしても閲覧可能。

### 表示試案アルゴリズム

- 連続した3階に同じ**局所外壁列/辺分類**がある場合、中央階の**表示役割**だけが両隣と異なる「孤立フリップ」を検出する。
- 同一列で隣接する2箇所を同時に書き換えない（他の補正との非干渉）。補正1箇所あたり階間表示変化を正確に2つ減らす。
- 床・屋根・外壁の実際の幾何、辺分類、列の存在/欠落、候補出典、ハッシュは変更しない。重複・欠落や原本ドリフトは拒否する。
- この規則は表示上の一貫性だけを評価し、窓やフィンの設置・開口・安全・美観を証明しない。見た目の単調化という欠点もあり得るため採用可否は未決定。

### 再現手順（Node.js、オフライン）

```sh
cd source
node verify-b53-package.mjs
node --test parallel/b53/main/compile-b53.test.mjs
node parallel/b53/main/run-b53.mjs
```

`run-b53.mjs --export` は JSON/HTML が **両方存在しないときのみ**新規作成するため、凍結済み原本を上書きしない。

### 安全境界

`NOT_PREPARED` / 施工前M4 **9/9 BLOCKED** / `executionAllowed=false` / `BuildPlan.operations=[]`。施工、スキャン、Minecraft・Bridge・WS・HTTP 接続、実ブロック/材料指定、エンジン呼び出しは0。ローカル座標はワールド座標ではない。今回のビジュアルマーカーは実際の窓/フィンではない。実プランナー `composeFacade` および `architectural-quality.js` / `architectural-library.js` が未収録で、本番パリティは **UNVERIFIED**。旧ファイルは一切変更しない。

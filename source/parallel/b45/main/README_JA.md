# B45 — 5棟30階・マクロ形状非施工プランナー

## 今回実装したもの

- **B44 A/B/Cのピン留め済み成果**を入力として、5棟30階を非実行型デザイン工程175ノードへ一括コンパイル。
- 全階の床原形、候補切り欠き（未適用）、外側/中庭境界、屋根露出、室内壁候補、通常ドアポート、階段リンクを同時に照合する。
- 階毎の局所Y範囲を繋ぎ、段状に後退したオフィスの屋根露出を上階差分から再計算する。
- 5棟の外観コンセプトを**採用前の選択肢**として添付し、窓用の模様1,134か所を描画用に生成（窓開け・ブロック指定ではない）。
- OBJ + MTLの**5棟分のローカル3Dマッシング・プレビュー**を再現可能に出力。外側壁/中庭壁/屋根/床/仮想窓マーカーを別グループに分類。
- ドア位置世代差118、未切り欠き50セル、階段25リンク、通常ドア314、9施工ゲートBLOCKEDを保持。

## 再現コマンド

`cd source` 後:

```bash
node verify-b45-package.mjs
node --test parallel/b44/sub-a/circulation-b44a.test.mjs parallel/b44/sub-b/structure-b44.test.mjs parallel/b44/sub-c/sub-c.test.mjs parallel/b44/main/integrate-b44.test.mjs parallel/b45/main/compile-b45.test.mjs
node parallel/b45/main/run-b45.mjs
```

`node parallel/b45/main/run-b45.mjs --export` は**まだB45成果ファイルのない独立コピー上のみ**使用可。存在するファイルを上書きしない（排他 `wx`）。配布ZIPはレポートとOBJをすでに含む。

OBJはBlenderなどのOBJ対応ビューアで開ける。関連MTLも同じフォルダに置くこと。**表示座標は建物ごとのローカル座標であり、現実・Minecraftワールド座標ではない。** 5棟間の配置関係は定義していない。

## 厳格な未解決条件

- `BuildPlan.operations=[]`、`NOT_PREPARED`、全M4-01～09 `BLOCKED`、Bridgeや実ゲーム呼出0。設計データを実行エンジンへ渡すコードは無い。
- 5棟30階の幾何マクロ**データが整った**という意味であり、建築プランナー・物理素材・壁支持・窓・階段・ドア状態・実通行性は完成していない。
- 1棟の動線78/78は壁24セル再設計を仮定した概念値、他4棟の動線は未検証。L1床にはSubA側のL2候補代用という限界がある。
- 仮想窓マーカー1,134件は壁のパターン候補。**窓穴・外壁開口・実ブロックではない**。MTLの表示色をMinecraft素材と混同しない。
- B44の厳格な`verify-b44-package.mjs`は追加ファイルがあると停止する。そのまま維持してあり、代わりにB45専用検証器が**B44全723ファイルの内容を1バイト単位で保護**する。

## B46の推奨優先順位

1. このパイプラインの5棟共通の屋根・立面デザインを**実用的な候補**へ絞り、支持と窓候補の交差を解決する。デザイン変更を反映したプレビューは施工と分離する。
2. 開発用プランナーでの**read-only構造投影**を段階的に統合し、ブロック材料や外部座標が確定するまではコマンド生成を絶対禁止する。
3. サブA・B・Cは未解決項目が単独の作業量として十分に大きいタイミングで再稼働。メインで一括処理できるなら無理に並列化しない。

# B49 — 非施工アーキテクチャ・インターフェース統合アトラス

## 目的と実装範囲

B48の**全5棟30階、canonical floor/roof/shell geometry**を起点として、既存B46のグラフィック外壁・開口候補・内部構造ヒントを**1つの監査可能な下流設計レポート**に関連付けた。元のプランナーやMinecraftには接続せず、幾何に限定して処理する。

1. **外壁リボン分割**：B46の外壁走査（3,022 unit edges）を壁の向き・中庭／外周別に保持し、既存の**窓表示用1,134単位／縦フィン表示326単位／未割当辺**に重複なしで分割。水平帯100ランは独立して表現。見た目の設計候補であり、窓の穴開けや材料の指定ではない。
2. **入口位置の候補列挙**：B48の参照前面5か所についてプランナーが許す区間を始点列として列挙し、既存の窓／フィンとの衝突（**表示上の見直し必要性**）を記録。入口の選定は行わない。`quality.entranceBias`、実際のドア形状、`ground.inset`、外部通路のつながりは未固定。
3. **屋上モジュールの上限幾何**：ピン留め参照プランナーにある「最上階最大矩形、横幅ホテル5／それ以外3上限、奥行3」の幾何だけを参考に、各棟の屋根露出セル上に収まる仮想水平位置候補を列挙。`quality.secondary`が有効な場合のみ生成され得る参照処理であり、`quality.roofVariant`・屋上方針・屋上接続・支持強度は未知。候補を施工可能な設備に変換しない。
4. **外壁の上下方向連続性**：各階外壁座標の同一性から、連続して存在するローカル外壁辺をまとめる。柱・梁・材料・鉛直荷重の連続性を立証してはいない。
5. **内部リンク関連付け**：既存B46パケットから名目上の内部ドア候補314、間仕切りヒント5,704、未検証階間リンク25を読み取り、外壁・入口・屋根インターフェースと同じ棟・階に関連付けた。原本の採否は一切変更しない。

`B49_ARCHITECTURE_INTERFACE_ATLAS.json` は完全にローカル、不可逆な施工操作を一切含まない設計レビューデータ。`sourcePlannerInvocations=0`に相当する`runtimePlannerInvocations=0`。壁に開口は作らず、屋上にもモジュールを生成しない。候補数は自由度を示すだけで、正式な建築設計数ではない。

## 新規コード

- `compile-b49.mjs` — 純粋な外壁リボン・入口候補・屋上候補・内部の関連付け、再計算・不変検査
- `run-b49.mjs` — B48を静的に再生して B49 を構築。出力書込は `--export` 時のみ、書き込み先の既存ファイルは `wx` で保護
- `compile-b49.test.mjs` — 非施工、安全条件、素材の不使用、幾何・改ざん防御、ピン留めソースを対象とする28件のテスト
- `B49_ARCHITECTURE_INTERFACE_ATLAS.json` — 実際に得られた設計レビューデータ
- `source/verify-b49-package.mjs` — 全B48凍結ファイルのハッシュ固定とB49追加差分の整合性検証

## 実行方法

```bash
cd source
node verify-b49-package.mjs
node --test parallel/b49/main/compile-b49.test.mjs
node parallel/b49/main/run-b49.mjs
```

出力JSONを削除・改変しない。必要な場合だけ、別ワークスペースで `node parallel/b49/main/run-b49.mjs --export` を実行すると新規ファイル作成できる（同名が既存なら失敗）。

## B50への具体的な次工程

B49は**静的幾何と視覚意図の合流**を終えたが、ゲームエンジンの実プランナーを起動したのではない。B50では、十分にハッシュ固定した `qualityComposition` / `composeFacade` / entrance・roofモジュールの仕様が入手できる場合のみ、既存のアトラスを使って**ファサード実際のモジュール割付・接合候補のオフライン再現可能性**を検証する。資料が不足する場合は曖昧な推定で「完成」と主張しない。生のコマンドは生成せず、安全条件を維持する。

## 絶対遵守

- `NOT_PREPARED` / 全M4 9ゲート `BLOCKED`、`BuildPlan.operations=[]`。
- 既存建築、Legacy、B48までの全凍結ファイルを**バイト単位で不変更**。
- Minecraft Education、Bridge、WebSocket、HTTP、Windows実スキャン／実施工の**実行禁止**。
- 元プランナーをimport/呼出ししない。ブロックID・ワールドアンカー・材質などを作らない。`constructionApproved=false`。
- Codex・サブチャット未使用。新プログラムはNode標準モジュールと既存の非施工設計コンパイラのみ。

# B57: Architecture Envelope Topology and Local 3D Reviewer

これはB53原本由来の**ローカル概念座標**での独立形状検証であり、Minecraftの建築エンジン本体ではありません。B56ソースゲートを引き継ぎ、正規ソース未取得の状況で、検証可能な形状的性質を具体的に固定します。

## 主要成果

- 5棟・30階の床12,778セルと屋根2,228セルを矩形配列から独立にラスタ化する。
- 各階の床セル4近傍から外壁エッジを独立に再生成し、B53の表示マーカー3,022単位と座標単位で集合一致を検証する。
- 床と上階の差分から露出屋根を再生成し、屋根矩形をセル単位で検証する。
- 連結成分、下階の平面被覆、囲まれた空洞の壁を判定する。これは構造強度や階段アクセスを保証しない。
- 既存3方針×5棟の入口正面境界と屋上候補の平面被覆を監査（位置の概念照合に限定）。
- HTMLのローカル3D模式ビューア：建物・設計案・階・視点・外壁表示の切替。Canvas 2Dで疑似3Dを描画し、外部CDNや通信は使わない。色は**実建築素材ではない**。

## 実行（オフライン）

```sh
cd source
node verify-b57-package.mjs
node --test parallel/b57/main/compile-b57.test.mjs
node parallel/b57/main/run-b57.mjs
```

HTMLは`parallel/b57/main/B57_OFFLINE_3D_REVIEW.html`をダウンロードしてブラウザで開く。開くことはMinecraftへのアクセスではない。

## 絶対的な安全条件

`NOT_PREPARED`、施工前9ゲートBLOCKED、`BuildPlan.operations=[]`、施工命令・Minecraft接続・スキャン0。原本エンジンは読み込まない。B56以前のファイルは一切上書きしない。ファサード機能の本番パリティは `UNVERIFIED`、物理建築品質は `UNKNOWN`。

### B58の優先

原本をB56のZIP受入れにかけ、正規ファイルバイトが揃う場合のみ静的実装分析に進む。ない場合はこのB57の外形検証を**実装物と勘違いさせず**、改めて本番の内装/外壁/素材生成規則と突合する証拠収集に焦点を当てる。必要な場合のみWindowsの読み取り専用収集をユーザーへ依頼する。

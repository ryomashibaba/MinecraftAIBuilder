# B67 Windows原本収集ツール / 非施工・読み取り専用

**最優先で実行してほしい操作は1回です。** Windowsで `RUN_B67_READONLY.cmd` をダブルクリックしてください。

- Node.js 20以降を使用します。Windowsにインストール済みのNode.jsで動く設計ですが、**Windows実機では未検証**です。
- 自動で `minecraft-ai-builder` プロジェクトを見つけられなければ、**プロジェクトフォルダをCMDへドラッグ＆ドロップ**して再実行します。候補の一般的な保存場所だけを検査し、PC全体は検索しません。
- 出力先：`ダウンロード/MinecraftAIBuilder_B67_Readonly_SourceEvidence_*.zip`。保存先はソースプロジェクトの外側です。
- ファイル本体5件＋検証メタデータのみを格納。JSやプロジェクト内コードを**実行せず**、読み取り専用。通信・Minecraft・ブリッジ・スキャン・施工なし。
- **アップロード前に必ずZIPの中身を見て秘密情報が含まれていないか確認してください。** 原本コードが入ります。
- `PINNED_MATCH=5` でもゲームで動作することは意味しません。`VERSION_MISMATCH` はファイル版が異なるだけで、自動で更新・承認されるわけではありません。
- 本番ファサード・部屋の施工可否はまだUNVERIFIED。M4 9ゲートBLOCKED、NOT_PREPARED、operations=[] は一切変更しません。

## 次チャットの再開
生成ZIPをこのチャットにアップロードし、「B67原本ZIPの5ファイルを**実行せず静的照合**してB68に進んで」と依頼してください。必要な場合はB67統合引継ぎZIPも一緒に添付します。

## 機械検証済み範囲
Node.jsのスタンドアロン収集器は合成fixture上で実行し、B56の既存ZIP受入れ器と互換性を検証します。**WindowsのCMD実機UI、実Windowsパス、実本番ファイルの読み出しは未実行**です。

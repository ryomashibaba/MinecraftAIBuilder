# ARK-LITE-P0 — Minecraft Education 大型未来ターミナル

本体とは別ブランチ。B175の巨大モデルを完全再現する計画ではありません。

## 建物

- 幅48、奥行40、高さ30ブロック（Y=0..29）。玄関アプローチを含む前後範囲はZ=-4..39。
- 床、外壁、ガラス天窓付き屋根、幅12×高さ7の正面入口、外観を強調する4本の塔、正面アーチ、照明、歩ける広い1階ロビー。
- 正確なブロック数・実行コマンド数は offline --inspect か Actions試験で確定する。
- 内装・上層階・階段は今回実装しない。
- ゲーム実機での施工・歩行結果はまだ未確認。CIは実機完成の証明ではない。

## Windows操作：専用の空のテストワールドだけ

1. GitHub Actionsの「ARK-LITE-P0-Windows-Test-World」成果物を1回だけダウンロード・展開し、START_ARK_LITE.cmdを起動。既存B137と同じsocket-be 2.8.0を初回だけnpmで導入する。
2. Minecraft Educationで破棄可能な空のテストワールドを選ぶ。チート/コマンド実行を有効にする。床の起点 X Y Z は、設置対象48×44×30の範囲が空気で、床Yの直下に安全な地盤がある場所を選ぶ。
3. CMDの「1」は読み取り専用。テストワールド名と起点X Y Zを入力。範囲はX=起点..+47、Y=起点..+29、Z=起点-4..+39。
4. Education内で /wsserver 127.0.0.1:8000 を1回入力。対象セル全数の空気確認と玄関内部32サンプル確認を行い、占有・未知・通信エラーはHOLD。
5. **事前にこのチャットで、テストワールド・座標・施工内容・撤去方針を明示し、ユーザーが実施工を承認した場合に限り**、同じCMDの「2」を使用。ワールド名とプランのハッシュを含む長い確認文字列を入力する。施工時も全セル再検査、keepで空気だけ設置、全セルreadbackと耐障害ジャーナル記録を行う。
6. ゲーム画面で建物内外を目視・歩行してから実機完成判定をする。出力JSONは data/ARK_LITE_LAST_REPORT.json。中断・再開と撤去には data/ARK_LITE_STAGE_JOURNAL.json を残す。
7. テスト後の撤去はCMD「3」＋専用確認文字列。ジャーナルに記録された書き込み対象のみ、想定材料と一致したときだけ条件付きで空気に戻す。変更されたブロックは除去しない。

## 読み取り専用検査の速度改善（P0 Performance Update）

- 従来の4並列から標準16並列へ変更。実機の処理量と通信負荷によって短縮率は変動し、実測結果がない段階では何倍と断定しない。
- `Read-only full survey` は対象7,363セルを引き続き全数検査する。負荷を理由に安全検査をスキップしない。
- 施工モードは、全サイト検査で取得した各runの空気セル数を再利用し、以前の二重化した設置前チェックを省略。各施工コマンドは `keep` で空気セルのみ設置し、直後に各runを並列で厳密照合する。従来約22,000件だった調査・設置前検査・照合の読み取りは、通常の新規施工で約14,760件になる（事前制御検査を含む）。
- 照合やコマンドに異常があればHOLD。成功するまでワールドの建築完了とは扱わない。遮蔽物が調査と施工の間に置かれた場合、`keep` は上書きせず、照合不一致で停止する可能性がある。
- 処理が不安定な機器では、同じCMDを起動する前にWindowsコマンドプロンプトで `set ARK_LITE_READ_WORKERS=4` を指定すると読み取り並列数を下げられる（許可範囲1～32）。
- P0座標制限はEducation対応の -64～319 に合わせて修正。Y=-60 の床は範囲上有効だが、実際の占有状態は必ず調査する。

## 安全の限界

- socket-be経由ではゲームのワールド名を独立に検証できないため、ワールド名はオペレーターの自己申告。間違ったワールドに接続しないこと。
- 施工対象セルはすべて検査するが、未施工の内部空間すべてが空気かまでは全数検査しない。必ず空のテストワールドを使う。
- Bedrock/Educationのkeep/filtered replace構文は公式Bedrock資料と照合したが、現行Education実機での動作は未検証。
- 維持する安全条件：本体readiness=NOT_PREPARED、9ゲートすべてBLOCKED、constructionApproved=false、BuildPlan.operations=[]、worldContacts=0、worldWrites=0。専用テストワールドの施工は本体ゲートを解放せず、別ジャーナルにのみ記録する。
- 作業ブランチはfeature/prototype-ark-lite-ee-20261017。mainや本格建築ブランチへ無断マージしない。
